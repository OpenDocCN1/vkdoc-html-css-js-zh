## 引言

在开始之前，先提个醒：生成式艺术，以及更广泛的创意编程，可能会成为一种让人沉迷的瘾。"再来一次迭代"是你可能从那些身陷其中的不幸艺术家口中听到的口头禅。创意工作者渴望下一次生成式创作的快感，并恰好掺入恰到好处的随机性。

本书的目的是以清晰、合乎逻辑的方式，小剂量地揭示这种计算魔法，让你能够安全且神志清醒地接触这个主题。我们将见证由机械精确性诞生的有机形态，不可预测的色彩铺满屏幕，线条与形状以不可思议的和谐汇聚，以及从简单规则中涌现出的复杂结构。这便是生成式艺术的精髓——一切并非尽在你掌控之中。

话虽如此，对于艺术家而言，这也是一种需要时间、耐心和技巧的媒介——其要求绝不亚于其他艺术媒介。虽然我可能夸大了它对实践者的掌控力，但我真正想表达的是，编程拥有其富有表现力的一面——它可能会令人沮丧、让人头疼，这是肯定的——但它也能引人入胜并激发灵感。如果我能为你装备一些新的生成式工具和技术，并在这个过程中让你对其创造潜力略感兴奋——这些潜力超越了艺术领域，延伸至设计和 Web 开发——那么本书就远远完成了它的使命。

### 你需要了解什么

作为读者，在阅读本书之前需要了解些什么？如果你对编程的核心概念，如`变量`、`函数`、`循环`和`条件语句`感到得心应手，那么学习过程无疑会更加轻松。这类概念在不同的编程语言中大同小异，主要区别在于语法，因此即使你之前使用的是 JavaScript 以外的语言，也完全没问题。

如果你没有任何编程经验，我们将在第 2 章介绍所需的概念，但我必须强调，本书并非一本编程入门书籍。最好将第二章视为一本入门手册，一个让你在其他地方更深入学习的跳板。一门简短的入门课程对你会有很大帮助。我个人推荐出色的[`freeCodeCamp.com`](https://freeCodeCamp.com)，我自己也花了大量时间在这个网站学习。它提供了关于`HTML`、`CSS`和`JavaScript`基础知识的免费交互式教程，以及其他更多内容。

对于来自其他语言（如 Python、PHP 或 C#）的读者，阅读第二章可能仍然有价值，以确保你熟悉`JavaScript`的语法和一些特性。

如果你已经是一名有经验的 Web 开发者，根据你的经验水平，可以跳过（或快速浏览）第 2 章。如果你对我们开篇示例（我们将以此结束第 1 章）中使用的任何技术或语法不熟悉，我鼓励你阅读第二章，那里会对它们进行详细解释。Web 开发领域非常广阔，对一位开发者来说驾轻就熟的内容，对另一位开发者来说可能还是前沿技术。

### 你将学到什么

我前面提到过，将为你配备一些新工具和技术。现在让我们来详细说明一下。

#### 工具

在工具方面，我们将使用以下内容：
* `JavaScript`和`SvJs`库。我稍后会详细说明这一点。
* 一个代码编辑器。这里我将为你提供两种选择：
    * `Visual Studio Code`（一个优秀的开源代码编辑器）
    * `CodePen`（一个流行的在线代码编辑器）
* 如果你选择使用`Visual Studio Code`（我推荐），我们还将使用`Node.js`和`NPM`来管理依赖项（这是作为开发者应该养成的良好习惯）。

所有代码示例都可从`GitHub`和`CodePen`上获取，所以请随意按照你喜欢的任何方式跟进学习。你当然可以两种方式都采用：在本地使用代码编辑器工作，同时在线查看`CodePen`示例以快速获取灵感。为方便起见，我会将所有`CodePen`示例整理并嵌入到[`davidmatthew.ie/generative-art-javascript-svg`](https://davidmatthew.ie/generative-art-javascript-svg)。

### 技术概览

就我们将涉及的技术而言，读完本书后，你应该会对以下内容有一个良好的整体认知：
- `SvJs` 库的主要功能及其与 SVG 规范的关系
- 使用 ES6+ 语法，通过 JavaScript 创建生成式艺术草图
- 生成基础的 SVG 形状
- 通过随机化参数创建草图的迭代变体
- 使用噪声创建有机变化
- 生成复杂的 SVG 路径
- 制作交互式草图
- 为草图添加动画效果
- 以生成方式使用 SVG 滤镜

我们将涉及大量内容，所以不必给自己太大压力，强求理解一切。我自己也常常在某个编程概念上反复碰壁无数次后才终于豁然开朗（JavaScript 的 Promise 机制，有人懂吗？），而每次真正理解的时候，通常是因为我在尝试构建一些*真正想做*的东西，而不是机械地重复教程步骤。教程和指导性书籍当然有它们的价值（否则我也不会写这本书了），但重要的是你要从中汲取*你自己*需要的东西，而不是把它们当作必须严格遵守的教学大纲。

保持游戏感很重要，尤其是在艺术创作中。虽然我之前提到了工具，但我更希望你将这本书视为一个玩具箱，而不是工具箱。当我想到工具时，我想到的是需要解决的问题，比如那个歪斜的橱柜上你一直说要去拧紧的松动铰链。工具往往更注重功能性而非趣味性，而我更希望你能从这本书中获得一些乐趣。
