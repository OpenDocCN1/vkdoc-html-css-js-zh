

# 设计思维

设计思维是一套用于规划和创建以人为中心的设计问题的产品与解决方案时，所运用到的战略性和创造性流程及原则。

本系列以设计与创新为两大关键驱动原则，重点关注但不限于以下领域和主题：
* 用户界面 (UI) 与用户体验 (UX) 设计
* 设计心理学
* 人机交互 (HCI)
* 人因工程学设计
* 产品开发与管理
* 虚拟现实与混合现实 (VR/XR)
* 以用户为中心的建筑环境与智能家居
* 无障碍性、可持续性与环境设计
* 学习与教学设计
* 策略与最佳实践

本系列丛书面向行业内的设计师、开发者、故事讲述者和问题解决者，旨在帮助他们了解当前创造力前沿的最新发展和最佳实践，创建新的范式与解决方案，并激励创意工作者突破边界，设计出比以往更宏大、更卓越的作品。
