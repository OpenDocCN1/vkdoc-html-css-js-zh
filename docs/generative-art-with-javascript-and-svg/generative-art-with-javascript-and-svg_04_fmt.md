# 2. 编程入门

虽然编程可以用于创作艺术，但它本身也是一门艺术。它既是科学也是艺术。开始学习编程时，你需要先熟悉其科学的一面，即构成编程这门学科的基本概念和规则。艺术的一面可以稍后涉猎。

学习编程基础意味着要掌握值、变量、运算符、表达式、条件语句、循环、函数等概念。如果你对这些概念一无所知，请不要担心。这正是本章的目的。

我们还将介绍 `JavaScript`（我们选择的语言）的特性（包括一些特殊之处）。`JavaScript` 是一种强大且极其流行的语言；它是浏览器原生理解的唯一编程语言，因此，它自然无处不在。学习 `JavaScript` 是一个非常实用的选择，它不仅在生成艺术领域，在许多其他领域也能发挥巨大作用。

## 语法

我们从一些语法要点开始。

### 大小写敏感

`JavaScript` 是一种区分大小写的语言，因此 `JavaScript` 和 `javascript` 这两个词会被视为不同的标识。许多程序员在命名函数或变量时遵循的命名惯例是驼峰命名法，即术语以类似骆驼驼峰的方式连接在一起。例如：

```
thisIsCamelCase
soIsThis
```

如你所见，术语的第一部分完全小写，后续部分使用我们称之为“标题大写”的形式，即每个单词的首字母大写。

### 空格

与一些强制执行严格缩进的语言不同，`JavaScript` 中的空白字符没有内在含义。间距主要是一种风格问题。在 `JavaScript` 社区中，你遇到的最普遍的风格约定是使用两个空格来缩进代码，如下所示：

```
someCode() {
  some indented code
}
```

### 分号

`JavaScript` 中的每个语句都应该以分号（`;`）结尾，它相当于自然语言中的句号。由于 `JavaScript` 具有一项称为“自动分号插入 (ASI)”的功能，你可以选择完全不写分号，但这样做并不总是安全的（而且我也使用其他必须使用分号的语言），因此我选择保留分号。本书中的代码都将包含分号。

### 注释

在任何你编写的代码中，养成大量使用注释的习惯非常重要。这不仅能让其他人更轻松地阅读和理解你的代码，也能让你自己做到这一点。你会惊讶地发现，如果没有注释指引，自己的代码也会很快变得像谜题一样难以理解。

`JavaScript` 中有两种类型的注释：单行注释和多行注释。单行注释以两个正斜杠 `//` 开头，多行注释以正斜杠和星号 `/*` 开头，以星号和正斜杠 `*/` 结束。

```
// 单行注释。适用于快速解释。
/*
 * 多行注释。
 * 适用于恰当地记录代码。
 */
```

单行注释也可以放在同一行代码之后。

```
someCode(); // 我们可以在这里安全地写注释。
```

## 值

作为一名程序员，你必须精通各种值及其类型。这里我们不是在谈论道德价值观或编程道德准则；这里说的值，指的是最终会被简化为计算机处理的字节和比特的信息“块”。值可以是任何东西，从数字到文本字符串（例如“我爱早餐麦片”）。让我们从数字开始。

### 数字

如果说计算机有什么特别钟爱的东西，那就是数字。它们处理数字的速度，远比我吃掉我最爱的早餐麦片的速度要快。在某些编程语言中，存在不同类型的数字（例如，`int` 代表整数或整型数字，`float` 代表十进制数或浮点数），但在 `JavaScript` 中，所有数值都属于单一的 `Number` 类型。

```
17 // 一个整数。
23.085 // 一个小数。
4e2 // 一个带指数的数字（这里表示 4 的 2 次方）。
```

### 字符串

字符串表示文本信息，如单词和句子。字符串需要用引号括起来，可以是单引号或双引号。

```
'世界上有 10 种人。' // 单引号
"懂二进制的人和不懂二进制的人。" // 双引号
```

无论你选择使用单引号还是双引号，保持一致非常重要。尽量不要随意混用。

另一种类型的字符串称为模板字面量，它允许你将变量和表达式插入到字符串中。这是标准的单引号或双引号无法做到的。模板字面量被反引号括起来，代码可以插入在以美元符号为前缀的花括号之间，如下所示：

```
`这里是一些文本 ${someCodeHere}，这里还有更多文本。很酷吧？`
```

这是 `JavaScript` 的一个较新特性，在处理连接字符串和多行字符串时非常有用。让我们通过一个例子来说明。

```
// 这是过去开发者存储多行 HTML 字符串数据的方式。
let oldWay = '' +
'    \n' +
'<div>\n' +
'        我的名字是 ' + name + '，我今年 ' + age + ' 岁。\n' +
'</div>\n' +
'    \n';

// 这是现在实现同样事情的方式。
let newWay = `
<div>
  我的名字是 ${name}，我今年 ${age} 岁。
</div>
`;
```

如你所见，它更加易读和简洁。通常，每当你想要将字符串值与任何其他内容混合时，反引号是最佳选择。

### 布尔值

布尔值是二进制的；它们只能是 `true` 或 `false`。它们以布尔代数的发明者乔治·布尔的名字命名。它们可用于表示任何二元状态：是或否、开或关、活着或死亡等等。它们简单地写成 `true` 或 `false`。

```
let alive = true; // 呼，还活着
let kicking = false; // 只是坐着
```

布尔值使得条件语句和比较成为可能，我们稍后会讲到。

## 空值

空值是我们最后要介绍的值类型。共有两种：`null` 和 `undefined`。你可以将它们理解为不携带任何信息的值。在调试代码时你会经常遇到它们（尤其是 `undefined`），所以可以想象，它们并非总是受欢迎的访客。

`null` 和 `undefined` 有什么区别？一种简化的理解方式是：当 `JavaScript` 告诉你一个名为 `x` 的变量是 `null` 时，它是在说：“我知道 `x`，但据我所知，`x` 目前没有任何值。” 另一方面，如果它告诉你 `x` 是 `undefined`，那基本上是在说：“`x` 是个什么鬼？这里压根没有 `x` 这玩意儿。”

## 变量

我们已经多次提到过“变量”这个词，那么它们到底是什么呢？你可以把变量想象成存储值的容器，这些值可以在后续被引用。

变量在使用前必须先声明。有三种声明方式：使用 `const`、`let` 或 `var`。其中，`var` 已不再推荐使用；我提到它主要是出于历史原因，并且因为你在实际代码中很可能会遇到它。现在很多很多的 `JavaScript` 代码库仍然在使用 `var`，仅仅是因为在 2015 年那次重大的 `JavaScript` 更新（称为 `ECMAScript 6`，简称 `ES6`）之前，没有其他选项可用。

声明一个变量需要使用关键字，创建一个名称/标识符，然后使用等号运算符为其赋值。

```
const name = 'David Matthew';
const countryOfBirth = 'Ireland';
let age = 21; // 我希望如此！
```

`const` 和 `let` 有什么区别？使用 `const` 时，你声明的值是不应更改的。我的 `countryOfBirth` 就是一个例子：这是一个恒定不变的历史事实。如果之后我试图给 `countryOfBirth` 重新赋值，会导致错误：

```
countryOfBirth = 'Brazil'; // 哎呀...
-> TypeError: Assignment to constant variable
```

然而，我的 `age`（唉）是会变化的，所以可以毫无问题地更新它。`const` 和 `let` 的另一个区别是，`let` 可以在声明时不赋值，而使用 `const` 时，必须在首次创建时就为其赋值。

```
let a; // 没问题。
const b; // 自找麻烦。
-> Uncaught SyntaxError: Missing initializer in const declaration
```

如果不确定，应该使用 `const` 还是 `let`？`JavaScript` 社区的普遍共识是，你应该默认使用 `const`，只有当认为变量之后可能被赋予新值时，才使用 `let`。理由是这样可以减少意外的值重新赋值，从而排除一个潜在的 bug 来源。

## 运算符

运算符是对值执行运算的符号。我们实际上已经见过一个了：赋值运算符（`=`），它将一个值赋给一个变量。让我们看看还有哪些其他类型的运算符可供使用。

### 算术运算符

你可能已经猜到了，算术运算符允许我们执行数学运算。加法运算符（`+`）允许我们相加数字，但它也允许我们拼接字符串。

```
// 数字相加。
2 + 2
-> 4
// 字符串拼接。
'I am' + ' so smrt'
-> 'I am so smrt'
```

还有减法（`-`）、乘法（`*`）和除法（`/`）运算符。

```
// 数字相减。
9 - 4
-> 5
// 数字相除。
9 / 4
-> 2.25
// 数字相乘。
9 * 4
-> 36
```

# ES6 运算符与控制结构

ES6 引入了指数运算符（`**`），它允许你计算一个数的另一个数次方。

```
// 指数运算符。
2 ** 2
-> 4
2 ** 6
-> 64
2 ** 10
-> 1024
```

最后，还有取模运算符（`%`）。它将一个数除以另一个数，并返回余数。这在循环遍历数组（我们稍后会讲到）时，或者快速判断一个未知数是偶数还是奇数时，会特别有用。

```
// 取模运算符的使用。
3 % 3
-> 0
3 % 2
-> 1
12 % 5
-> 2
```

## 运算符优先级与比较符

在此，值得提及运算符优先级规则，它决定了运算执行的顺序。助记词 `BEMDAS` 可以帮助我们理解。

- `B` 括号：括号或圆括号内的内容最先计算。
- `E` 指数：接下来计算指数。
- `M` 乘法和 `D` 除法：然后是乘法和除法。这两者具有相同优先级，因此按书写顺序（即从左到右）计算。
- `A` 加法和 `S` 减法：对剩余数字进行加法和减法。与乘法和除法一样，这两者优先级相同，且从左到右计算。

```
// 这些求和表达式看起来相似，但结果不同。
4 / 2 * 2 + 4
-> 8
4 / 2 * (2 + 4)
-> 12
4 / 2 ** 2 + 4
-> 5
```

如有疑问，请使用括号对运算进行分组。这也可以提高可读性。

### 比较运算符

顾名思义，比较运算符对值进行比较。它们始终返回一个布尔值，即 `true` 或 `false` 值。

- `<` 是“小于”运算符。
- `<=` 是“小于或等于”运算符。
- `>` 是“大于”运算符。
- `>=` 是“大于或等于”运算符。
- `==` 是“等于”运算符。
- `===` 是“严格等于”运算符。

由于 JavaScript 工作方式存在一些微妙的特性，我建议坚持使用严格版本的相等运算符。这可以减少意外（即 bug）。

```
// 比较运算符的一些示例。
1 > 2
-> false
2 < 3
-> true
3 >= 3
-> true
5 == "5"
-> true // 但实际上并非如此。
5 === "5"
-> false // 这样才更准确。
```

### 逻辑运算符

最后，还有逻辑运算符：与（`&&`）、或（`||`）和非（`!`）。它们模拟了经典逻辑中的合取、析取和否定。

当使用 `&&` 连接两个条件时，当且仅当两个条件都为 `true` 时，结果才为 `true`。

```
true && false
-> false
false && true
-> false
true && true
-> true
```

使用析取（即“或”的正式说法）时，首先要确保在键盘上使用正确的字符。`|` 字符既不是大写字母 `I` 也不是小写字母 `L`；它被称为管道符。根据你的区域键盘布局，它可能位于回车键或 Shift 键附近。

当使用 `||` 时，如果一个或两个条件为 `true`，则结果为 `true`。如果我们记住我们实际上是在询问计算机“这些条件中至少有一个为真吗？”，那么这在直觉上是合理的。

```
true || false
-> true
false || true
-> true
false || false
-> false
```

最后，我们还有否定运算符 `!`。它会“翻转”紧随其后的条件。它还可以与相等运算符独特地结合，表示“不等于”（`!==`）。

```
!true
-> false
!false
-> true
1 !== 2
-> true
!(2 > 1)
-> false
```

新手程序员常见的一个错误是使用单个管道符 `|` 或单个 `&` 而不是两个组合。单独使用这些字符会执行位运算（即操作二进制值），这仅适用于高级编程。

## 条件语句

现在我们掌握了比较运算符和逻辑运算符，可以继续学习条件语句了。JavaScript 中的条件语句允许我们影响程序的控制流。打个比方，想象一下四向交叉路口高峰期的交通，人行道上挤满了行人。没有某种控制交通流的方式，就会一片混乱。这时就需要条件语句，例如可能支撑交通灯系统的各种规则。

```
// 基本语法。
if (conditionIsTrue) {
// ... 运行一些代码
}
// 一个简单的行人过马路条件语句。
if (pedestrianBtnIsPressed) {
wait(30s);
activateRedLights();
wait(3s);
activateGreenManSignal();
}
```

对于基本的 `if` 语句，我们还可以附加 `else` 和 `else if` 条件。

```
if (a > b) {
doThis();
} else if (a === b) {
doThat();
} else {
doOtherThing();
}
```

如果给定的条件不为真，则花括号内的代码不会被执行。让我们以之前的例子为例，为 `a` 和 `b` 填充值。

```
let a = 3;
let b = 4;
if (a > b) {
doThis(); // 条件不成立，因此此代码不运行。
} else if (a === b) {
doThat(); // 此代码也不运行。
} else {
doOtherThing(); // 以上两个条件均为假，因此运行此代码。
}
```

我想介绍的最后一个条件形式是三元运算符。顾名思义，它严格来说是一个运算符，但由于它扮演了条件检查的角色，我觉得将其放在这里更合适。

```
// 三元运算符的基本结构。
conditionA ? expressionIfTrue : expressionIfFalse;
```

在上述结构中，我们询问“`conditionA` 是否为真？如果是，则运行 `expressionIfTrue`。否则，运行 `expressionIfFalse`。”

三元运算符最适合用于当你希望根据某个条件是否成立来为变量赋值时。如果该条件不成立，则为其分配一个不同的值。这正是我在第一个生成式草图中使用它的方式：

```
const svgSize = window.innerWidth > window.innerHeight ?
window.innerHeight : window.innerWidth;
```

这里，我们在说“如果窗口的 `innerWidth` 大于其 `innerHeight`，则将 `innerHeight` 赋值给 `svgSize`。否则，将 `innerWidth` 赋值给它。”

## 循环

循环是程序员的一项超能力。我们说的是开天辟地的力量。或者，至少是能够让你的程序螺旋式奔向无穷的能力，可能会冻结任何打开的浏览器窗口，并使你的 CPU 风扇疯狂旋转。这是因为循环可以一遍又一遍地重复代码块，次数不限，或者根据需要无限进行。然而，通常明智的做法是为循环行为设置一个限制（无限循环更多时候是一种错误而非目标）。我们通过所谓的终止条件来设置循环的限制，即告诉循环何时停止的条件。

这里我们将介绍两种主要的循环：`while` 循环和 `for` 循环。

### While 循环

`while` 循环是两者中较简单的一种。其基本结构如下：

```
while (condition === true) {
// 当条件为真时在此处运行代码。
}
```

现在，如果所讨论的条件始终评估为 `true`，那将导致无限循环。因此，任何循环结构中的一个重要成分是一个在循环运行时发生变化的值。这通常是一个递增或递减的数字，被称为迭代器。按照惯例，`i` 通常用作变量名。

```
// 设置迭代器。
let i = 0;
while (i <= 99) {
// 将 i 的值写入浏览器控制台。
console.log(i);
// 每次循环运行时将 i 增加 1。
i = i + 1;
}
```

上述循环将运行 100 次，从 0 开始，直到小于或等于 99 为止，并且在每次迭代中，它会将 `i` 的值记录到浏览器控制台。如果省略了递增 `i` 的代码，它将无限循环下去。

值得一提的是，现在有一些简写方式来递增和递减——或者实际上乘法和除法——变量值：

```
// 长方式。
i = i + 1
i = i * 2
i = i – 1
i = i / 2
// 较短方式。
i += 1
i *= 2
i -= 1
i /= 2
// 更短方式（仅适用于加 1 或减 1）。
i++
i--
```

简写表示法是你实际编程中可能遇到的，因此我们在这里继续使用它。

### For 循环

`for` 循环使用与我们的示例 `while` 循环相同的逻辑，但将迭代器和递增操作合并到一行中。其典型结构如下：

```
for (let i = startingNumber; i < upperLimit; i += increment) {
// 当 i 小于 upperLimit 时运行一些代码。
}
```

`for` 循环结构简洁地分为三个部分。我们首先初始化迭代器，然后设置终止条件，最后决定如何变化迭代器。以下是之前示例的 `for` 循环版本，我们在每次迭代中将 `i` 的值记录到浏览器控制台。

```
for (let i = 0; i <= 99; i++) {
console.log(i);
}
```

你不一定总是递增迭代器。只需稍作调整，就可以轻松反转循环，使其从 99 向下计数到 0。

```
for (let i = 99; i >= 0; i--) {
console.log(i);
}
```

在`for`循环体中，经常将迭代器的值与其他变量结合使用，以实现某些动态结果。例如，在我们开篇的生成式草图中，我使用`i`逐步增加每个椭圆的`radiusX`和`radiusY`。

```
// 运行一个循环（随机次数）来创建我们的椭圆。
for (let i = 0; i < randomised.iterations; i += 1) {
// ... 代码。
let radiusX = 100 + (i * 3);
let radiusY = 300 + (i * 2);
// ... 更多代码。
}
```

关于循环，还有更多值得喜爱的地方，并且也存在其他变体（例如`for in`、`for of`和`forEach`，我们将在后面介绍），但就生成式艺术而言，我们主要会使用标准的`for`循环。

## 函数

函数对于 JavaScript 这门语言来说是基础，并且可能是我们在本章中将介绍的最重要的概念。函数是执行特定任务的独立代码块。该任务在函数体中定义，其范围可能从将两个数字相加到启动火箭发射序列。

标准函数使用`function`关键字定义，后跟您为其指定的名称，然后附加圆括号以及定义任务的开闭花括号。

```
// 标准函数的基本语法。
function peformSomeTask() {
// ... 定义任务的代码。
}
```

### 函数参数

尽管函数用途广泛，但它们的主要目的是使代码可复用。实现这一点的一种方法是向函数添加参数，这些参数在函数名称的圆括号内定义。

```
// 带参数的函数。
function sayHello(name) {
// 用爱尔兰方式向用户打招呼。
console.log(`Howaya ${name}, what's the craic?`);
}
```

函数可以显式返回值，也可以不返回。如果返回值，则只允许一个返回值。在前面的例子中，没有返回值，因为那不是该函数的目的（或者从技术上讲，如果查询该函数，将返回`undefined`值）。然而，在下面的例子中，我们专门希望从函数中获取一个返回值，这时我们就使用`return`关键字。

```
// 另一个带参数的函数，这次返回一个值。
function squareNumber(number) {
return number * number;
}
```

当调用上面的函数时，它会`return`我们想要的结果，即我们提供的数字的平方。但我们实际上如何在实际中做到这一点呢？

### 调用函数

要使用我们定义的函数，我们需要调用它。这等同于执行或运行该函数。可以这样做：

```
// 调用一个函数。
performSomeTask();
```

要调用在其定义中包含参数的函数，我们需要为其提供实参。实参是我们在调用函数时赋予函数的实际值。而形参则是我们定义这些值的方式。让我们看看如何调用带实参的函数。

```
sayHello('Dave');
-> "Howaya Dave, what's the craic?"
console.log(squareNumber(4));
-> 16
```

在这里，我们为第一个函数提供了实参`'Dave'`，为第二个函数提供了实参`4`，并得到了预期的输出。但如果我们在调用函数时忘记了实参，会发生什么？让我们试一下。

```
sayHello();
-> "Howaya undefined, what's the craic?"
squareNumber();
-> NaN
```

我们之前遇到过`undefined`，但没遇过`NaN`。`NaN`的意思是“不是一个数字”。在这两种情况下，我们的函数在缺少参数时都无法正常工作。我们该如何修复这个问题，让它们更健壮一些？

一个直接的方法是在定义函数参数时指定默认值。我们以重写`sayHello()`函数为例。

```
function sayHello(name = ", ah it's yourself") {
// 以爱尔兰人的方式问候用户。
console.log(`Howaya ${name}, what's the craic?`);
}
sayHello();
-> "Howaya, ah it's yourself, what's the craic?"
```

如你所见，创建默认值只需在定义参数时为其赋值即可。现在我们创建了一个比`undefined`更人性化的回退值。

对于`squareNumber()`函数来说，默认值就没那么有意义了。相反，我们可以使用前面介绍的三元表达式技术，在函数被无参数调用时提供一些可操作的反馈。

```
function squareNumber(number) {
return number ? number * number : '请包含你想要计算平方的数字';
}
```

在`squareNumber()`函数体内，三元运算符本质上是在问：“`number`是否已定义？如果是，则返回它自身相乘的结果；否则，返回我们的回退消息。”

至此，你应该能更好地理解第一个生成式草图中的函数了。再看一遍，看看现在是否更清晰了。

```
function random(min, max, integer = true) {
let random = Math.random() * (max - min) + min;
let number = integer ? Math.floor(random) : random;
return number;
}
```

## 作用域

变量的作用域指的是它的可见性，即在程序的什么地方可以访问该变量。在使用函数时，这一点尤其重要。

例如，如果我们在函数内部定义了一个变量，它只能在该函数内部可见。

```
function scopeTest() {
const a = 1;
}
console.log(a);
-> Uncaught ReferenceError: a is not defined
```

然而，如果我们在函数外部定义了同一个变量，它将在函数内部可见。

```
const a = 1;
function scopeTest() {
console.log(a);
}
scopeTest();
-> 1
```

在第一种情况下，变量是块级作用域的，即局限于函数块内。在后一种情况下，变量是全局定义的（在所有函数外部），可以在程序中的任何位置访问。

虽然能够在程序中的任何位置访问变量似乎更有利，但对于全局变量，我们应谨慎使用。通常来说，最好明确限制变量的作用域。这也是`var`被废弃的主要原因之一，因为它不能像`let`和`const`那样被“束缚”。

```
function scopeTest() {
var a = 1;
}
console.log(a);
-> 1
```

如你所见，使用`var`时，变量可以突破周围块级作用域的限制，这在大型程序中可能会带来问题。在编写生成式艺术时，我们通常编写相对较小的程序（或“草图”），全局变量的问题并不那么突出。不过，我们将在下一节讨论如何最好地让某些设置在整个草图中全局可用，而不依赖全局变量。

## 匿名函数

函数不一定总是需要有名字。尤其是在处理事件和回调（我们将在后面的章节中介绍）时，函数通常作为函数表达式被匿名调用，以便返回一个值。匿名函数也可以赋值给变量，然后由变量存储返回的值。

```
// 一个赋值给变量的匿名函数表达式。
const sum = function(a, b) {
return a + b;
}
```

在前面的例子中，该变量可以用来执行函数。

```
sum(5, 4);
-> 9
```

对于匿名函数，我们有一件事不能做：不能在语句的开头使用它们。

```javascript
// 下面这样写是不允许的。
function(a, b) {
return a + b;
}
-> Uncaught SyntaxError: Function statements require a function name
```

## 箭头函数

到目前为止，我们介绍了用 `function` 关键字声明的函数，但还有一种更现代的函数书写方式。这类函数因其采用的箭头语法而被称为箭头函数。

```javascript
// 箭头函数的基本语法。
const performSomeTask = () => {
  // ... 定义任务的代码。
}
```

它们是刚刚介绍的传统函数表达式的简洁替代方案。我们来重写 `sum()` 函数作为示例。

```javascript
const sum = (a, b) => {
  return a + b;
}
```

如你所见，代码简短了一些。但如果我们的函数只包含一个返回值的语句（这正是我们的 `sum()` 函数的情况），它甚至可以变得更简洁。在这种情况下，我们不需要花括号，甚至不需要 `return` 语句本身。

```markdown
# 箭头函数

```javascript
const sum = (a, b) => a + b;
```

由于箭头函数体仅包含单个语句（`a + b`），因此系统会默认我们希望返回该语句的值。这就是所谓的`隐式返回`。

当然，并非所有箭头函数都能如此简洁地精简，只有那些包含单一返回语句的才行。但这种单行写法在现代 JavaScript 代码库中广泛使用，尤其是使用像 React 这样声明式前端框架的代码库，因此熟悉它们非常值得。

使用箭头函数还有另一个原因，这稍微超出了本章的范围，那就是 `this`。我指的是 `this` 关键字，这在 JavaScript 中是一个复杂的话题（并且在不陷入指代混乱的情况下解释清楚也很复杂）。简而言之，在箭头函数中使用 `this`，其值更可预测，也更不容易引发错误。但现在先别担心 `this`。

相反，让我们关注一些数据结构，它们在生成式艺术以及更广泛的 JavaScript 应用中会很有帮助。这是我们下一节的内容。

## 对象与数组

当需要定义数值、字符串和布尔值等值时，变量非常有用，但如果你需要更复杂的方式来组织和表示数据该怎么办呢？比如，你有一长串列表——无论是本周的购物清单、公司的员工名单、你希望在辞世前游历的地点，或者回到生成式艺术的话题上，你打算为下一部怀旧风格杰作采样的 216 种网络安全色的十六进制代码（在 1990 年代，当时的网页开发者——那时被称为网页管理员——可用的调色板要受限得多）。当你需要处理任何形式的列表时，数组就是你的好帮手。

### 数组

数组本质上是一个可以容纳多个值的变量。在 JavaScript 中，这些值不必是同一类型。这意味着如果需要，我们可以将数值、字符串和布尔值混合放入同一个数组中（不过并不推荐这样做）。

数组采用以下格式：

```javascript
// 标准数组的语法。
let arrayName = [item1, item2, item3, ... itemN];
```

每个数组元素都有一个对应的`索引`（即数字），代表其在数组中的位置。数组中第一个元素的索引为 `0`（计算机中从零开始计数是常态），第二个元素索引为 `1`，第三个为 `2`，以此类推。要按索引直接访问数组中的元素，需要使用方括号，如下所示：

```javascript
// 访问第一个元素。
let firstItem = arrayName[0];
// 访问第二个元素。
let secondItem = arrayName[1];
// 访问第 n 个元素。
let nthItem = arrayName[n + 1];
```

这种方式特别适合与循环配合使用。使用 `for` 循环遍历数组中的元素是一种非常常见的做法，并且在我们整个生成式艺术之旅中会频繁用到。

让我们继续以网络安全色为例，遍历包含这 216 个十六进制值的数组。

```javascript
// ... some code.
circle.fill(webSafeColours[i]);
// ... more code.
```

在图 2-1 中，您将看到此代码片段的输出。显然，实现这种螺旋排列涉及更多内容（我们将在后面的章节中介绍）；重点是，我们如何使用迭代变量 `i` 循环遍历每个颜色值，即 `webSafeColours[i]`。

![一张抽象图显示了在深色背景上以螺旋模式排列的各种阴影数据点。](img/538894_1_En_2_Fig1_HTML.png)

**图 2-1** 网络安全色螺旋

如果您勇敢地检查示例背后的代码，您会注意到我最初使用了一个名为 `push()` 的数组方法将每个颜色添加到数组中。相关的代码行是：

```javascript
colours.push(colour);
```

`push()` 方法是我们将项目添加到数组末尾的方式（可以想象从后面装卡车）。如果我们想将项目添加到数组的开头，我们使用一个名为 `unshift()` 的方法。

```javascript
colours.unshift(colour);
```

如果我们想从数组末尾移除一个项目，我们使用 `pop()` 方法（想象一下爆米花从锅中爆出）。相反，如果我们想从数组开头移除一个项目，我们使用 `shift()` 方法（之所以这样命名，是因为我们将所有剩余项目向下移动一个索引）。

在继续之前，我想介绍另一个方法，即我之前提到的 `forEach()` 循环。此方法是数组特有的，它依次对数组中的每个项目执行操作，使用一个函数作为其参数。顺便提一下，以这种方式作为参数传递的函数被称为回调函数。

```javascript
// 设置一个示例数组。
const someNumbers = [2, 4, 6, 8, 10];

// 对每个数组项目调用 forEach 方法。
someNumbers.forEach((item) => {
  console.log(item * 2);
});
// -> 4 8 12 16 20
```

如果循环的主要目的是专门为每个数组项目执行某些操作，那么 `forEach()` 循环是一种非常简洁的遍历数组的方式。

### 对象

对象是 JavaScript 提供的另一种数据结构，和函数一样，它们是该语言的基础特性。深入观察，您会发现对象无处不在。事实上，函数是一种特殊的对象。

与数组类似，对象可以包含多个值。主要区别在于，对象用名称标记其值，而数组用数字（即每个项目的索引）标记其值。

对象的格式如下：

```javascript
const objectName = {
  name1: value1,
  name2: value2,
  name3: value3
};
```

这些名称-值对就是对象的`属性`。这些值可以是任何你想要的东西：字符串、布尔值、函数、数组，甚至其他对象。几乎所有能想到的东西都可以表示为一个对象。以我的笔记本电脑为例。

```javascript
const myLaptop = {
  processor: "Core i5",
  screenSize: "14 inches",
  inSleepMode: false,
  powerUp: function() {
    if (inSleepMode) {
      wakeUp();
    } else {
      runBIOS();
    }
  }
  // 等等
}
```

有了这些属性，我们可以使用方括号表示法或更常见的点号表示法来调用它们。

```javascript
// 使用点号表示法访问对象属性。
myComputer.screenSize;
// -> "14 inches"

// 使用方括号表示法访问对象属性。
myComputer[processor];
// -> "Core i5"
```

我们也可以通过相同的语法更新和创建新的对象属性。

```javascript
// 更新对象的属性。
myComputer.inSleepMode = true;

// 创建新的对象属性。
myComputer.storage = "512 GB SSD";
```

如果你重新审视我们的第一个草图，你会注意到我使用了一个对象来存储一些随机化设置，这些设置稍后在草图中被调用：

```javascript
const randomised = {
  hue: random(0, 360),
  rotation: random(-180, 180),
  iterations: random(10, 100)
};

let rotation = randomised.rotation + (i * 2);
```

这是解决我之前提到的全局变量问题的一个好方法。通过使用对象，我们可以使我们的设置全局可用，而不必依赖全局变量。这可以使我们的代码更整洁，并且更不容易引起冲突。

## 类

类（`Class`）就像是创建对象的蓝图或模板。创建出来的对象被称为该类的一个`实例`。一个类可以包含数据以及操作这些数据的函数。这种数据和代码的耦合被称为封装。我们不会深入讲解类的细节，但了解一些基本术语会很有用，因为我们即将使用的 `SvJs` 库就是基于类的。

要创建类的实例，我们使用 `new` 关键字，后面跟上类名和括号。这会调用该类的 `constructor`（构造函数）。

```javascript

class StarShip {
  // ...
}

// 实例化（或构造）一个类。
const prometheus = new StarShip();
```

属于类的函数被称为方法。一个类通常至少包含用于获取和设置其属性的方法。

```javascript
prometheus.setDestination = 'Moon LV-223, Zeta 2 Reticuli';
prometheus.takeOff();
```

```

## 奇异性与其他特性

JavaScript 提供了许多其他特性，包括闭包、错误捕获、代理、Promise 等等，但我无法在此全部涵盖。我将在此指出的是 JavaScript 的一些怪癖——或者客气点说是`古怪之处`——这些可能会困扰使用其他语言的程序员。

### `null`和`NaN`的怪异之处

我们之前了解到`null`本质上就是信息的缺失。那么，`null`也`被认为是一个对象`，这难道不奇怪吗？我们可以通过使用`typeof`检查来确认这一点。

```
typeof null;
-> object
```

尽管如此，`null`并不被认为是对象的实例。我们可以通过使用`instanceof`检查来确认这一点。

```
null instanceof Object;
-> false
```

`NaN`（非数字）同样呈现出一些量子级别的怪异，足以让薛定谔的猫都竖起耳朵。它显然不是一个数字，但同时却等于一个数字。而且，奇怪的是，它甚至不等于自身。

```
typeof NaN;
-> Number
NaN === Number;
-> false
NaN === NaN
-> false
```

### 隐式类型转换

JavaScript 在幕后做一些来自更严格语言背景的程序员可能不总是欣赏的事情。例如，它在数据类型方面是出了名的松散，并会根据情况将不同类型的变量转换为匹配的类型（转换数据类型的过程也称为`类型转换`）。让我们以一些数字为例。

```
1 == 1;
-> true
1 == "1";
-> true
```

一个数字怎么可能等于一个字符串？嗯，它不能。JavaScript 正在将字符串转换为数字以便理解表达式。它本质上是在将字符串数据强制转换为数字数据（也称为`类型强制转换`）。这就是为什么我们最好在 JavaScript 中使用严格相等运算符的原因，这在许多其他语言中是不存在的。

```
1 === "1";
-> false
```

当我们尝试将数字与字符串相加时，也会发生这种转换，但方向相反；在这种情况下，数字被转换为字符串。

```
1 + "2";
-> "12"
"2" + 3;
-> "23"
```

为了避免这种隐式类型强制转换的陷阱，可以使用像`parseInt()`、`parseFloat()`和`toString()`这样的函数来重新转换或显式地将变量转换为你想要的数据类型。

### 分号的不确定性

我在本章开头提到过，如果你愿意，可以不用分号编写 JavaScript，但在某些边界情况下，这可能导致意外行为。这里就有一个这样的边界情况。

```
return
1 + 2
-> undefined
```

在 JavaScript 中，空格无关紧要，那么这里发生了什么？为什么表达式没有返回`3`？嗯，这里`自动分号插入`功能在幕后被调用了。实际被评估的代码是这样的：

```
return;
1 + 2;
```

为了避免这种情况，要么熟悉这类边界情况，要么就使用分号。
