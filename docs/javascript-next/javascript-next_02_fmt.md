# 致谢

写书是一项孤独的追求。然而，我们站在巨人的肩膀上——无论是过去、现在，还是未来的巨人。这包括我们的家人、老师和导师，他们向我们展示了努力和自律的价值；也包括那些在我们之前的科技工作者，他们创造了我们有时觉得理所当然的东西；最后，还有那些如今不知疲倦地推动边界、改善现状的人们。我知道自己很幸运，有机会受到许多这样杰出人物的影响——正在阅读这本书的每一位，你们知道你们是谁，以及你们对我意味着什么。谢谢你们。

我有幸在许多会议上发表过演讲，但有一个名字尤其令我难忘，那就是 No Fluff Just Stuff (NFJS) 会议系列。我非常感谢 NFJS 的主管 Jay Zimmerman 给了我机会，也感谢该系列的其他演讲者，他们不断给我灵感并分享他们的经验。这本书是我有机会就这个主题演讲一段时间的结果，但它的核心内容来自于我与世界各地数百位聪明、有才华的开发人员的互动，是他们让我质疑自己对概念的理解，并促使我深入探究。

感谢 Brian 和 Anne Sam-Bodden——我长期的雇主，更重要的是，我的朋友——你们对我能力的信心总是超过我自己。你们鼓励我成为演讲者，并鼓励我写书。你们为我提供了一个可以实验、最终茁壮成长的环境。我将永远感激你们。

特别感谢我的朋友兼导师 Venkat Subramaniam 博士。Venkat 是我在个人和职业生活中的建议和友情方面所依赖的人，尽管他的日程安排非常紧张，但他总能抽出时间倾听我的想法，并提供公平、公正的视角（虽然经常用老爸笑话，但效果很好）。

感谢 Apress 的所有同仁，是他们让这本书成为现实，包括 Louise Corrigan、Nancy Chen 和 James Markham——感谢你们的耐心和辛勤工作。与你们合作非常愉快。

尽管所有参与本书审阅、编辑和校对的人付出了最大努力，但书中任何及所有的疏漏和错误都由我一人承担。

我想向我更好的另一半 Michelle 表达我的爱和感激。她耐心地处理了生活中所有琐事，包括照顾我们的两个儿子 Mason 和 Micah，而我则像个隐士一样专心写这本书。当然，我也不能忘记提我们的另外两个“孩子”——约克贵宾犬 Buddy 和拉布拉多贵宾犬 Skye——感谢它们提供了坚定不移的陪伴和无尽的娱乐。特别感谢我的父母和姐妹们，他们虽然从不承认，但正是他们塑造了今天的我。

最后但同样重要的是，我要向您——本书的读者——致敬。您的注意力是宝贵的资源，我感谢您将花在本书上的时间。祝学习愉快。
