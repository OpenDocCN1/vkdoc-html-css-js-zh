# 总结

默认参数让我们在定义函数签名时更具表现力。它们用合适的默认值替代了多余的检查，从而使代码的意图更清晰。默认参数值在调用时求值，允许我们在程序的运行时上下文中延迟设置参数。由于参数可以“看到”函数签名中左侧定义的参数，我们可以尝试实现多态函数，并启用其他语言中可能使用的“重载”方法的概念。

剩余参数消除了在编写多参数函数时使用 `arguments` 对象的必要性，其额外好处是提供了显式函数签名支持。这有助于消除代码中不必要的强制转换，并提供一种机制来干净地捕获所有未被参数占用的参数。

默认参数和剩余参数都不能取代良好 API 设计的必要性；事实上，它们起到了相反的作用。通过强调从左到右优先级递减的参数，它们迫使我们区分哪些参数是必需的且必须提供，哪些是我们可能能够设置默认值的。

所有这些都减少了客户在使用我们的 API 时必须承担的上下文开销。这难道不值得庆祝吗？
