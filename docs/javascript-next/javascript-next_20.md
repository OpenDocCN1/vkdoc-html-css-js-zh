# 总结

在本章中，我们了解了 JavaScript 现在如何提供一种标准的迭代机制，使得序列的生产者和消费者能够遵循一套规范的 API 进行迭代。我们还了解了生成器函数和对象如何允许我们编写惰性代码以及生成无限序列。虽然生成器的相关机制看起来可能很复杂，但记住可迭代对象和生成器所提供的对称性会有所帮助——它们恰好是一枚硬币的两面。
