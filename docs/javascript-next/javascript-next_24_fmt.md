# 总结

JavaScript 一直支持类型和继承的概念，尽管其方式有些繁琐，并且需要深入理解（构造）函数、原型和实例之间如何相互作用来让一切神奇地发生。在本章中，我们学习了如何使用像 `class` 和 `extends` 这样的新关键字来清晰地阐明我们的实例应该是什么样子。我们还着重强调了这样一个事实：在底层，这种新语法仅仅是原型继承的语法糖，以及总是以“面向对象”模式思考可能带来的陷阱，而有时函数式思考可能对我们更有利。

在下一章中，我们将重点介绍模块，它试图填补 JavaScript 中的一个迫切需求，即模块，一劳永逸地替代我们为代码“命名空间”而想出的所有方案。
