## 引言

JavaScript 无处不在——它在客户端运行单页应用程序，在服务器端使用（借助`Node.js`等技术），帮助使用`Electron`^(¹)构建桌面应用程序，并且可以用于像`Raspberry Pi`^(²)这样的单板计算机。JavaScript 甚至可以使用`TensorFlow.js`^(³)等技术在浏览器中训练机器学习模型。总之，JavaScript 可以说是世界上部署最广泛的语言——每台台式电脑、笔记本电脑以及每部装有浏览器的手机都能运行 JavaScript。如今，JavaScript 展现了许多人们期望一个拥有如此庞大应用范围的语言所应具备的特性。

但情况并非一直如此。

JavaScript 有着悠久的历史，在撰写本书时已有 24 年之久。在此期间，JavaScript 从一种用于动画网页的脚本语言，演变为一种无处不在、无所不能的语言。然而，JavaScript 的名声却先于其本身——它被认为古怪且容易出错，而这些批评并非毫无道理。包括负责 JavaScript 发展的核心委员会`TC39`^(⁴)在内的所有人，都注意到了这一点。

2015 年，`ES6`发布，为这门语言引入了一系列新特性和语法变化。其目标很简单——用开发者们所渴求的特性武装 JavaScript，使其进入现代 Web 时代，并为该语言的未来版本奠定基础。

结果如何呢？一门旨在提升开发者体验的语言，其结构对于来自其他语言的开发者来说似曾相识。同时，还宣布了发布未来版本的年度节奏，确保 JavaScript 持续演进和成熟。

默认参数、对可变函数、解构语法和箭头函数的支持等功能，使得更容易发挥 JavaScript 的函数式特性，从而编写出简洁优雅的代码。同时，新添加的类语法使得轻松构建继承层次成为可能，允许库和框架作者提供必要的“支架”供开发者接入和扩展。

异步编程是 JavaScript 固有设计的自然结果，而 JavaScript 的新增功能再次让事情变得更容易。Promise 现在是一个原生 API，为全新的抽象层次打开了大门，我们开发者可以在此基础上构建。其中两种这样的抽象是`async/await`，它们使用 Promise，并帮助编写异步代码，使其看起来几乎是命令式的。

还有更多！总而言之，如今的 JavaScript 感觉像是一种截然不同的语言——一种行为和表现都类似于开发者们可能习惯的其他语言的语言。

本书旨在向你介绍所有这些特性，力求对每个新增功能提供“是什么”和“为什么”的细致见解。然而，不实践就无法学习——所以本书提供了大量示例，每个示例都旨在突出一个特定特性。那么，让我们戴上开发者帽，启动编辑器，写一些代码吧。

准备好了吗？开始！

## 本书的读者对象

本书面向程序员、开发者、技术主管、架构师、编程爱好者，或者任何有兴趣了解 JavaScript 在过去 5 年中如何演变的人。如果你是一位曾因这门语言屡屡受挫而畏惧 JavaScript 开发的人，那么本书或许能向你展示这门语言如何变得更易于理解（对于熟悉其他语言的程序员而言），且不那么古怪。

## 本书内容概览

本书旨在成为`Ecmascript` (ES) 6、7、8 和 9 中所有增强功能的全面参考资源。每章开头都会指出语言中的一个缺陷或不足及其影响，然后介绍一项新的语言特性或补充，以及该变化如何解决特定的问题领域。

本书**不会**按时间顺序介绍新特性（从第 6 版一直到第 9 版）；相反，我旨在将多个版本中的特性汇集在一起，只要它们在逻辑上可以“共存”。但是，我会明确指出该特性是在哪个版本中引入的。

许多技术书籍都会逐章详细列出你在书中会找到的内容。说实话，我总是跳过这个列表，更倾向于坚持看目录，或者直接翻到索引去找我需要的内容。因此，我将省去自己几行字，也为你省点时间。希望你能理解，并或许能原谅这个省略。

## 本书未涵盖的内容

本书并不打算成为编程或 JavaScript 语言的全面参考资料。它假定你，读者，具备编程背景并对该语言有一定程度的熟悉。然而，语言中有许多我们过去可能未曾探索的部分，对于这些方面，如果我认为有必要，我会提供更深入的论述。

JavaScript 也经常对现有 API 进行修改、添加，偶尔还会弃用，这种趋势在该语言的较新版本中仍在继续。同样，本书不涉及这些内容；相反，它专注于语言的*语法*增强。

最后，有多种运行现代 JavaScript 的选择。这些包括像`Babel`^(⁵)这样的转译器。本书不会尝试涵盖如何使用任何此类工具，或记录相关的配置。
