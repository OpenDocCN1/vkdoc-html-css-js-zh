# 总结

`Proxy` 与 `Reflect` 一起，为我们提供了在代码中以非侵入方式创建“元”魔法所需的所有工具。`代理`为我们希望增强的对象提供了命名空间包装器，确保修改后的行为仅对适用的代码区域可见。`Reflect` 镜像了 `Proxy` 的 API，同时为 JavaScript 提供了一个专门的位置来存放反射相关的 API，而在 ES6 之前，是 `Object` 展现了一些反射能力。将 `Reflect` 作为工具集的一部分，使得 JavaScript 能够减少 `Object` 中的冗余，甚至可能开始弃用某些方法（如 `getPrototypeOf` 和 `isExtensible`）的使用。这两个类都允许我们以优雅的方式进行 JavaScript 元编程，我相信富有创造力的开发者们会找到极其有趣的用例来应用它们。

`Symbol` 允许我们向对象中注入行为，而`代理`（及`反射`）则允许我们修改对象周围的行为。结合 `Symbol` 和`代理`，元编程的二元性如今已完整呈现。我们可以并且应该选择最适合我们用例的正确工具。

在下一章中，我们将探讨 ES8 中引入的一个强大特性，即 `async` 和 `await`，它们神奇地允许我们像处理同步代码一样处理异步代码，从而消除了使用 Promise 时的大量语法开销。
