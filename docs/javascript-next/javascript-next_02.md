# 如何使用本书

本书中的示例遵循两大原则：短小精悍，且基于已学内容构建。在这方面，我相信我（基本）做到了。你可以在我们的在线代码仓库中找到本书所有示例，地址是 [`https://github.com/Apress/javascript-next`](https://github.com/Apress/javascript-next)。欢迎克隆或下载该仓库，然后按照其中的 `README` 文件中的使用说明操作。

或者，最简单的办法就是直接使用你的浏览器控制台。大多数现代浏览器，如 `Chrome` 和 `Firefox`，都自带控制台。你可以直接将本书中的示例复制粘贴到控制台中，随心所欲地进行实验。

就我个人而言，我更喜欢在文本编辑器中做实验。如果你和我一样，更习惯使用熟悉的工具，那么你需要安装 `Node.js`。按照 `Node.js` 官方网站上的说明进行安装。如果你已经安装了 `Node`，但又不想引入版本冲突，可以了解一下“`Node Version Manager`”或“`nvm-windows`”，它们允许你同时安装多个版本的 `Node`。

安装好 `Node` 后，在电脑上任意位置创建一个临时目录并进入该目录。然后创建一个名为 `hello-world.js` 的新文件，内容如下：

```javascript
console.log('Hello JavaScript!');
```

切换到终端，导航到你的临时目录，并执行以下命令：

```bash
node hello-world.js
```

你应该会看到以下输出：

```
Hello JavaScript!
```

你可以用这种方式运行本书中的所有示例。这种操作方法非常适用，除了第 12 章（关于模块的章节），在那章中我会提供额外的说明。

大多数编辑器都支持通过扩展、插件或构建系统在编辑器内部执行代码。请务必阅读你常用编辑器的文档，了解如何启用这一功能，以实现快速的反馈循环。无论你采用何种机制，都要确保始终使用正确的 `Node` 版本。

让我们开始编写一些现代 JavaScript 吧！
