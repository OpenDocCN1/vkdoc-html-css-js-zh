# 总结

尽管箭头函数与它们的表达式和语句表亲有几分相似，但它们在 JavaScript 新世界中的作用是无可争议的。它们使我们能够利用 JavaScript 固有的函数式特性，使代码更简洁、更易读，并且与常规函数不同，它们抑制了任何使其变得有状态的尝试。

在本章中，我们探索了胖箭头函数的新语法。我们看到了它们的语义与常规函数有何不同，并学习了箭头函数最能为我们服务的恰当使用场景。只要我们始终留意它们行为上的差异，箭头函数就会很好地为我们服务。

在下一章中，我们将探索一种定义函数签名的新机制，它可以使我们的代码更具表现力，同时减少我们习惯在函数内部进行的大量错误检查。
