# 总结

ES6 为我们提供了几种新的结构来在代码中声明和使用变量。`let` 和 `const` 允许我们使用一种更符合其他语言习惯的声明风格。它们的作用域规则使得代码推理更简单，从而防止了因使用 `var` 而经常引入的错误。随着浏览器厂商为我们提供对 ES6 及更高版本更好的支持，我们理应拥抱这些新的结构。展望未来，再也没有理由偏爱 `var` 了。`let` 和 `const` 提供了我们需要的一切，并在运行时内置了适当的检查。我们应该利用 linting 工具来强制实施这一点，无论是在开发阶段还是在持续构建过程中。
