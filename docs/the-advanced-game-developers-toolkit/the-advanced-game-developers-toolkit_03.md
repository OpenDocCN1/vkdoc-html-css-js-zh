# 关于作者与关于技术审校者

## 关于作者

![A346816_1_En_BookFrontmatter_Figb_HTML.jpg](img/A346816_1_En_BookFrontmatter_Figb_HTML.jpg)

Rex van der Spuy 是视频游戏设计和交互图形领域的顶尖专家，也是广受欢迎的《基础》和《高级》系列游戏制作书籍的作者。Rex 曾为 Agency Interactive（达拉斯）、Scottish Power（爱丁堡）、DC Interact（伦敦）、Draught Associates（伦敦）、蒙特利尔银行和 TVO（加拿大）设计游戏并进行交互界面编程。他还为 PixelProject（南非开普敦）的博物馆装置构建了游戏引擎和交互界面，并开发了世界上最小的全功能 2D 游戏引擎“Ga”以及其全功能姐妹引擎“Hexi”。他曾多年在印度加拿大学校（印度班加罗尔）创建并教授游戏设计高级课程。他职业生涯的亮点是在海拔 4500 米的安娜普尔纳冰川上编程制作视频游戏（令他高兴的是，这比他的笔记本电脑最高允许运行海拔高出了 1000 米）。Rex 的空闲时间用来睡觉和调音他的西塔琴。

## 关于技术审校者

Tom Barker 是一位丈夫、父亲、工程师、技术领导者、教授、作者、业余古典学者、有抱负的酿酒师和大师。目前，他是康卡斯特公司软件工程与开发的高级总监。
