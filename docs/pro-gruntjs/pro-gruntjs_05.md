# 关于技术审校者

**马特·吉福德** 是其自有开发咨询公司 Monkeh Works Ltd 的拥有者和主要负责人。他的工作主要集中在构建移动应用、前端开发、优化工作流程以及使用多种服务器端语言开发全栈 Web 应用。

他是一位出版过作品的作者，并在各种会议和用户组中就多种主题进行演讲。他也是社区资源和知识共享的积极倡导者。他是《ColdFusion 中的面向对象编程》和《PhoneGap 移动应用开发食谱》的作者，并为国际行业杂志撰写文章和教程。请访问 [www.monkehworks.com](http://www.monkehworks.com) 或在 Twitter 上关注 @coldfumonkeh 联系马特。
