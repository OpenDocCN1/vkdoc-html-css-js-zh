# 视口相对单位

视口相对单位包括视口宽度（`vw`）、视口高度（`vh`）、视口最小值（`vmin`）和视口最大值（`vmax`）。这些单位表示适用视口尺寸的 `1%`。例如，如果设备（或浏览器窗口）的视口宽 `600` 像素、高 `400` 像素，那么 `1vw = 6px`，`1vh = 4px`。`vmin` 单位基于视口的最小尺寸，在这种情况下为 `400` 像素，所以 `1vmin = 4px`。这与视口的方向无关。类似地，`vmax` 基于最大尺寸，所以 `1vmax = 6px`。

**提示：** 虽然严格来说不算“单位”，但距离尺寸也可以指定为百分比，例如 `width: 20%;`。按此方式定义时，宽度表示为包含元素的百分比。相比之下，`vw` 和 `vh` 是相对于初始包含块的百分比，初始包含块即整个窗口的尺寸。
