## 第一部分：HTML5 技术

### 第 1 章：超文本标记语言

#### HTML 文档

一个 HTML 文档由元素和属性构成，它们定义了网页的结构和内容。

#### 元素

元素是 HTML 的构建块，例如 `<div>`、`<p>` 和 `<span>`。

#### DOCTYPE

`DOCTYPE` 声明定义了 HTML 的文档类型和版本。

#### 属性

属性提供了元素的额外信息，例如 `class`、`id` 和 `src`。

#### 杂项结构规则

这些规则规定了元素如何被嵌套、闭合和格式化。

#### Html 元素

一个 HTML 页面的根元素是 `<html>`。

#### Head 元素

`<head>` 元素包含元数据和资源链接。

#### Title 元素

`<title>` 元素定义了文档的标题。

#### Meta 元素

`<meta>` 元素提供了元数据，例如字符集和描述信息。

#### Script 元素

`<script>` 元素用于嵌入或引用 JavaScript 代码。

#### Link 元素

`<link>` 元素定义了与外部资源（如样式表）的关系。

#### Style 元素

`<style>` 元素包含内联的 CSS 规则。

#### Base 元素

`<base>` 元素为相对链接设置了基础 URL。

#### 总结

本章涵盖了 HTML 的基础构建块。

### 第 2 章：层叠样式表

#### 样式指南

有效组织和应用样式的指南。

#### 组织内容

以可维护和可扩展的方式组织你的 CSS。

#### 应用样式

使用选择器、声明和规则来样式化元素。

#### CSS3 规范

CSS3 引入了新特性，如动画、渐变和弹性盒子（flexbox）。

#### CSS 概念

核心概念包括选择器、声明、单位和优先级。

#### 选择器

选择器用于定位特定的 HTML 元素进行样式化，例如 `.class`、`#id`、`element`。

#### 声明

声明由属性和值组成，例如 `color: red;`。

#### 单位

单位定义了度量方式，例如 `px`、`em`、`rem` 和 `%`。

#### 优先级

CSS 优先级决定了当样式冲突时应用哪个样式。

#### 样式表来源

样式可以来自用户代理、作者或用户。

#### 特殊性规则

特殊性用于计算哪个选择器具有更高的优先级。

#### Important 关键字

`!important` 关键字会覆盖正常的优先级规则。

#### 盒模型

盒模型描述了外边距、边框、内边距和内容之间的交互方式。

#### 厂商前缀

厂商前缀（例如 `-webkit-`、`-moz-`）确保跨浏览器的兼容性。

#### Style 属性

`style` 属性允许在元素上直接使用内联 CSS。

#### 总结

本章介绍了 CSS 的基础知识和布局概念。

#### 数组
