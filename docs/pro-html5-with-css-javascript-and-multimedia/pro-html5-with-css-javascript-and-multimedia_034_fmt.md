# 第二部分 - HTML

在本节中，我将讲解可用的 HTML 元素，以及如何以及何时使用它们。我在第 [1](http://dx.doi.org/10.1007/978-1-4842-2463-2_1) 章中已经介绍了其中一部分：那些用于提供文档结构和元数据的元素。现在，我将深入探讨 HTML 元素的核心内容。

HTML5 完全围绕语义展开；在本节中你会反复读到这一点。选择使用哪个元素至关重要，它传达了内容的含义或用途。

在接下来的五章中，我将尽力阐明*为什么*应该使用每个元素，当然，我也会提供*如何*使用它们的演示和示例。

本节中各章节的内容组织如下，每章描述一组元素：

- **4) 结构元素**，例如 `header`、`footer`、`section`、`aside` 和 `div`。这些元素创建了一个支撑其余内容的骨架。

- **5) 文本元素**——有大量主要包含文本内容的元素，每个元素都提供特定的语义含义。

- **6) 表格元素**——这些元素用于排列逻辑上属于行和列的表格数据。

- **7) 嵌入式元素**，例如 `img`、`audio` 和 `video`。

- **8) 表单元素**，包括 `input`、`button`、`label` 以及其他用于创建数据输入表单的元素。

## 第 4 章：HTML 结构元素

我在第 [1](http://dx.doi.org/10.1007/978-1-4842-2463-2_1) 章中简要介绍了 HTML 的基本语法，然后解释了 `head` 元素内部的信息。`head` 元素中没有可显示的内容；其中的数据供浏览器、屏幕阅读器或搜索引擎等应用程序使用。现在我们将注意力转向 `body` 元素；这里才是内容所在之处。

### 内容分类

HTML5 中定义了 100 多个元素。我在第 [1](http://dx.doi.org/10.1007/978-1-4842-2463-2_1) 章中已经解释了一部分，在接下来的五章中，我将演示其余的元素。元素按内容分类进行组织，并且基于这些分类存在通用规则，这些规则定义了元素可以在哪里使用以及它可以包含什么内容。

一个元素可以属于多个类别，也有少数元素不属于任何类别。

- **元数据** - 这些元素已在第 [1](http://dx.doi.org/10.1007/978-1-4842-2463-2_1) 章中解释过；它们没有实质内容，但提供关于 HTML 文档的元数据以及供处理文档的应用程序使用的信息。

- **分区** - 这些元素用于将页面组织成各个部分，也用于构建文档大纲。
