## 第一部分

### HTML5 技术

`HTML5`一词涵盖了广泛的技术，它们共同为 Web 应用程序开发提供了一个强大的平台。

# 构建出色 Web 应用的平台

这些内容可分为三个领域：

- `1) HTML` – 网络内容，包括标记指令。
- `2) CSS` – 定义内容呈现方式的样式规则。
- `3) JavaScript` – 提供客户端脚本和高级功能。

第一部分为每个领域都设有一章，介绍理解本书其余内容所需的基本概念。对于 Web 开发相对新手而言，这一部分不可或缺。每章还对该技术进行了广泛覆盖，因此即使你经验丰富，也很可能会发现一些未曾了解或可能遗忘的知识点。我建议每位读者至少通读这些章节。在研读更高级的章节时，你可能需要回来复习这些内容。
