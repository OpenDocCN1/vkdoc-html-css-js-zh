## 引言

我撰写本书的目标是提供您所需的一切知识，让您能够熟练创建利用 HTML5 所有优秀特性的专业级 Web 应用程序。我也希望这本书能对新手和经验丰富的专业人士同样有益。至于我是否实现了这些目标，最终由您来评判。

本书包含了大量信息，我深知组织好这些信息将是首要任务。整个 HTML5 保护伞涵盖了`HTML`、`CSS`和`JavaScript`；它们可被视为 Web 应用程序赖以生存的三脚架的三条腿。本书第一部分为这三项技术各提供了一章入门介绍。我建议您从这些章节开始阅读，特别是如果您对 Web 开发相对陌生的话。第 2、3、4 部分将更详细地分别阐述这三个领域。最后一部分则演示了一些高级主题，如 Canvas、SVG、拖放和 IndexedDB。

得益于 Mozilla、W3 Schools 以及许多其他组织和个人提供的非常有用的网站，有海量的现成资料可供参考。本书旨在通过主要聚焦概念来补充这些资源。如果您理解了基本原理，就能更轻松、更有效地应用特定功能的细节。不过，为了符合我的第一个目标，书中也提供了大量细节。我在附录 C 中收录了参考资料，以使正文更具可读性。

现在有令人印象深刻的一系列框架可供使用，例如`jQuery`、`Angular`、`Bootstrap`和`Knockout`。如果您正在从事任何严肃的 Web 开发工作，您会想使用其中一个或多个。这些框架并没有提供任何您无法通过我将演示的技术自行创建的功能。但是，如果您明智地选择并使用它们，它们将极大地简化您的工作。不过，在本书中，我将只关注 Web 技术的原生能力，不会使用任何这些框架。

您可以从[www.apress.com](http://www.apress.com/)下载每章的源代码。除最后一部分外，代码量保持相对简短，以便您可以边学习边自己输入。但为了方便起见，下载文件中提供了每章的最终代码。在某些情况下，我可能会演示两三种实现同一目标的方法。下载的代码中，有时会将这些情况下的部分代码注释掉。

我将解释的技术不依赖于特定平台或供应商。我将演示的示例网页应能在大多数主流浏览器上运行。您将编辑的文件——`HTML`、`CSS`和`JavaScript`——只是简单的文本文件，可以用任何文本编辑器编写。使用专为 Web 开发设计的工具，通过提供智能感知和上下文相关格式设置，将使您的工作更轻松。

我使用 Microsoft 的`WebMatrix`来创建本书的示例。`WebMatrix`免费且易于安装和使用。然而，微软计划在 2017 年 11 月停止对`WebMatrix`的支持，转而提供免费的开源版`Visual Studio`。除非您恰好已经是微软阵营的一员，否则这可能有点难以接受。但还有很多其他替代方案。您最喜欢的浏览器可能也提供了基本的编辑功能。

最后，与大多数技术一样，相关领域也在不断变化。我谨慎地选择了那些受大多数平台支持的功能进行描述，并避开了那些可用性有限的功能。当您阅读本书时，情况可能已经发生变化，您可能会发现某些信息已经过时。您可能需要针对特定功能自行研究。但我相信，借助本书中演示的基础知识，即使 HTML5 技术随着时间的推移而发展，您也能很好地利用它们。

祝您在掌握开发 Web 应用程序的所有精彩方面时取得圆满成功。学无止境！
