## 前言

你是否曾想成为罗丹那样的雕塑家，手握凿子，精雕细琢一块岩石，将其塑造成你心中的模样？主流程序员们一直对资源极度受限的移动设备敬而远之，唯恐无法雕琢出可用的应用程序。好吧，那样的时代已经过去了。

`Android OS` 将功能上近乎不受限制的移动设备（覆盖范围惊人）推送到了你的门前。在这本书中，我们想明确证实你的猜想：`Android` 是一个非常适合编程的卓越操作系统。如果你是一名`Java`程序员，你将拥有绝佳的机会，利用`Android OS`——这个令人兴奋、功能强大且通用性强的计算平台。尽管是移动操作系统，`Android OS`在框架设计方面引入了全新的范式。

这是我们对`Android`主题的第四版，也是至今最好的一版。*Pro Android 4* 是`Android 4.0 SDK`（第一个同时涵盖手机和平板的`Android` SDK）的全面编程指南。在这一版中，我们对*Pro Android 3*中的许多内容进行了精炼、重写和增强，为初学者和专业人士创建了一本彻底更新的指南。*Pro Android 4* 是我们四年研究的成果。我们在 31 个章节中涵盖了超过 100 个主题。

在本版中，我们加强了关于 Android 内部机制的讨论，涵盖了线程、进程、长期运行的服务、广播接收器、闹钟管理器、设备配置变更以及异步任务。我们用了超过 150 页的篇幅来讲解片段、片段对话框、ActionBar 以及拖放功能。我们显著增强了服务和传感器章节。动画章节也进行了修订，加入了基于属性的动画。联系人 API 章节也已大幅重写，以考虑为社交 API 铺平道路的个人资料功能。

概念、代码和教程是本书的精髓。每一章都体现了这一理念。每章中独立的教程都附有专家建议的注释。书中所有项目均可下载，方便导入 Eclipse。

最后，在本书中，我们超越了基础知识，就每个主题提出了尖锐的问题，并记录了结果（请参见目录中我们涵盖的广泛主题列表）。我们也在积极更新补充网站（`www.androidbook.com`），提供关于`Android SDK`的最新和未来研究资料。当您阅读本书时，如有任何问题，只需发送电子邮件，我们即可快速回复。
