# 引言

在开始之前，首先要感谢您的购买；没有像您这样好奇的读者，这本书就没有存在的理由。我很高兴能通过本书的各章节及更远的内容，与您一同踏上游戏开发之旅。我们将一起开发一款基于 Web 技术的休闲 Roguelike 游戏，并更深入地了解这一备受喜爱且经久不衰的游戏类型。

在本书结束时，您将拥有一个工具集和一个游戏，可以用来构建更复杂且更有成就感的 Roguelike 体验；您还将获得一系列链接和资源，用于进一步探索和学习通用游戏开发以及特定的 Roguelike 技术。

## 本书适合谁

本书面向对 Roguelike 游戏感兴趣的网络开发者和网络游戏开发者。您不需要成为`JavaScript`高手就能处理本书中的代码；我保持了代码的简单和灵活，以便初学者和中级开发者不仅能自信地理解源文件中的内容，还能随心所欲地进行修改。

如果您已经是一名 Roguelike 开发者，但一直使用不同的语言并且对 Web 技术感到好奇，那么本书对您来说将是一次有收获的体验。对于经验丰富的 Roguelike 开发者来说，书中展示的一些 Roguelike 技术可能显得基础；请记住，这只是一本入门书籍，任何旅程的第一步通常都是最简单的，而这些初步步骤对于该类型的新手来说是必要的。

## 如何阅读本书

我坚信技术实验的价值，因此我将本书的章节和代码组织得易于理解，并鼓励喜欢动手和好奇的读者深入探索。阅读每一章的最佳方式是先阅读并理解其中呈现的示例，然后大量地玩弄、塑造、制作、调整和实验这些示例，之后再进入下一章。

我们将构建的示例略显基础；它们缺乏让一款游戏成为“你的游戏”的特质。通过修改代码并掌握它，你将创造出独一无二的作品，这总是比我能构建的任何示例都更有成就感。

我们的方法是随着我们阅读各章节并构建更复杂的功能时，反复地工作和修改代码。就像任何 Roguelike 游戏一样，我们会遇到死胡同，会回溯，会找到并修复 Bug。这并不是要呈现一个完美的单一示例，让你从中掌握 Roguelike 开发的本质；而是要逐步构建，在学习中享受乐趣，并随着我们的想法和知识的发展而不断迭代。没有游戏是从一开始就完美开发的；所有游戏都经历迭代，我们的示例也是如此。

你的旅程从翻开下一页开始。
