# 接下来去哪里？

你旅程的下一步是深入了解 Roguelike 游戏。这里无法涵盖的内容还有很多；我们目前所做的不过是滑板车，而前方还有飞机等待你去研究学习。Roguelike 游戏是热爱的产物，许多开发团队投入数年甚至数十年来完善和改进他们的游戏。这也是一个非常有趣且平易近人的社区。我强烈建议你：

-   查阅 RogueBasin 中所有精彩的游戏和相关文章，那里是 Roguelike 信息的宝库。
-   观看 Roguelike Celebration 的精彩视频，这是一个面向 Roguelike 爱好者的国际会议，未来甚至可以考虑参与或演讲。
-   访问 Roguelike 开发子论坛，参与社区讨论。
-   获取更多关于 Roguelike 开发与程序化生成的书籍，尤其是优秀的《游戏设计中的程序化生成》。
-   参与 7DRL（七日 Roguelike 挑战赛），为其他开发者加油鼓劲——这是一个在线游戏创作马拉松，旨在制作小型 Roguelike 游戏。我可能会在下一次活动中提交一个强化版的《纳米地牢》……

如果你最喜欢的游戏开发语言是 JavaScript，可以在 RogueBasin 网站上找到专为 Roguelike 游戏设计的库。如果你更关注游戏类型而非语言，那么也有其他语言的库可用——Rust、Python、Lua、C、C++——选择非常丰富。你在本书中学到的技术，即便代码不同，也能迁移到其他语言和库中。

这只是你旅程的起点；你已获得一套简单的工具集，但即便只用简单的工具，我们也能创造出非凡的作品。我迫不及待想看到你将用它创造出什么。请保持联系，向我反馈意见并分享你创作的 Roguelike 游戏；我期待能玩到你制作的 Roguelike。
