# 关于作者与技术审校者

## 关于作者

**格雷姆·斯图尔特**

![A455241_1_En_BookFrontmatter_Figb_HTML.jpg](img/A455241_1_En_BookFrontmatter_Figb_HTML.jpg)

是一位自学成才的开发者，拥有 15 年使用 JavaScript、Ruby 和 Python 构建数据分析工具和网络应用的经验。他拥有能源管理博士学位，其大部分编程技能最初是为了实现这个目标而开发的。他曾在一段时间内向大学一年级本科生教授 JavaScript 游戏编程，本书正是由此而来。现在，他主要利用复杂性科学来鼓励对软件工程敏捷方法的深入理解，并证明他那些不寻常的研究雄心是合理的。

## 关于技术审校者

**阿迪亚·香卡**

![A455241_1_En_BookFrontmatter_Figc_HTML.jpg](img/A455241_1_En_BookFrontmatter_Figc_HTML.jpg)

于 1993 年开始编程，那时他第一次接触到计算机世界。当时无法访问互联网或在线教程，他通过在当地图书馆找到的一本书上吃力地重新输入代码，用 GW-BASIC 编写了他的第一个游戏。2001 年从印度理工学院马德拉斯分校毕业后，他作为软件顾问工作了近十年，为投资银行和大型财富 100 强公司开发交易和分析系统，最终离开企业生活，以便专注于自己热爱的事业。作为一名自认的技术极客，从那时起，他一直致力于自己的项目，并尝试每一种他能接触到的新语言和技术，包括 HTML5。在此期间，他因单枪匹马地完全使用 HTML5 重制了著名的即时战略游戏《命令与征服》以及《盟军敢死队：深入敌后》而声名远扬。除了编程，阿迪亚还热衷于台球、萨尔萨舞、健身和个人发展。他维护着一个个人网站，在上面撰写关于游戏编程、个人发展和台球的文章，并分享他广受欢迎的游戏演示。当阿迪亚不忙于写作或处理自己的项目时，他会为一些公司提供咨询服务，帮助他们推出新的软件产品和游戏。
