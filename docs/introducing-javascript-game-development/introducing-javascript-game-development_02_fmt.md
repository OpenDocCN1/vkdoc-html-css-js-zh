# 引言

本书提供了一套完整的练习，我们将通过这些练习构建一个功能完备的 HTML Canvas 游戏。虽然并非直接克隆，但该游戏的灵感来源于 1979 年雅达利的经典游戏《`小行星`》。书中为你提供了代码，并将在不同章节中逐一介绍。如果你想尝试《`小行星`》，或者从未玩过，可以在 [`atari.com/arcade#!/arcade/asteroids/play`](https://atari.com/arcade%23%21/arcade/asteroids/play) 玩到现代雅达利版本。对于本书中创建的游戏，我做了一些不同的玩法决策，如果你感觉有信心，我鼓励你在学习过程中尝试将游戏改编成你喜欢的任何方向。这都是很好的练习！

通常，每章都会以通用方式介绍游戏设计的一个领域，阐述如何将这些想法实现到《`小行星`》游戏的某个方面，并促使你思考替代方法。在本书接近尾声时，游戏将完成，你应该拥有构建自己高质量游戏所需的所有技能。

在大多数练习中，我们鼓励你发挥创意。仔细阅读提供的材料，思考提出的挑战，并探索修改所提供的代码会产生什么影响。设计这样的游戏没有“正确”的方法——它涉及做出许多决策，而所提供的代码只是数千种可能实现方式中的一种。所以，如果你觉得足够自信，请尝试用你自己的方式来做。这是学习新知识的好方法。
