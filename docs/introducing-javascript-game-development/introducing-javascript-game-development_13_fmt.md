# 第二部分

## 动画

使用 HTML Canvas 实现动画相当简单。我们只需要反复清除画布并绘制场景，每一步都更新场景即可。如果重复这个过程，并以每秒约 60 帧的速度绘制场景，那么我们就实现了动画效果。我们需要清晰定义场景中每个元素在每一步如何更新，确保将更新场景的代码与绘制场景的代码分开。接下来的章节将演示如何通过简单的游戏循环来控制动画，我们将学习设计游戏元素的扎实的面向对象方法的基础知识。最后，我们将使用一种简单的继承方法，为我们的"小行星"游戏克隆体开发一些必要的游戏元素。© Graeme Stuart 2017 Graeme Stuart《Introducing JavaScript Game Development》 `doi.org/10.1007/978-1-4842-3252-1_6`
