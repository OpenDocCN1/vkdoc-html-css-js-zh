# 1. 引言

现代世界充满了计算机。计算机运行着我们的手机、汽车，甚至冰箱。计算机管理着我们的业务、日程和社交生活。既然世界如此依赖计算机来完成众多功能，了解这些设备的工作原理就显得尤为重要。即使你永远不需要亲自为计算机编程，但在人生的某个时刻，你也很可能会参与到软件开发中。你或许是一名会计，需要告诉计算机程序员如何设置你的采购系统；你或许是一名工程师，需要描述你的工程流程，以便程序员将其自动化。在诸如此类的任务中，了解计算机是如何被编程的*一些*知识至关重要，即使你本人并非软件的编写者。

## 1.1 你将学到什么

在计算机编程时，程序员使用一种`编程语言`来告诉计算机如何执行操作。由于计算机并非智能生物，它们无法理解普通的人类语言。计算机理解一种被称为`机器语言`的语言，这将在第 5 章中进一步讨论。机器语言与普通人使用的语言截然不同。因此，编程语言被开发出来，作为程序员与机器之间的桥梁——它们比机器语言更接近人类，又比人类语言更接近机器。

多年来，人们开发了众多编程语言。你可能听说过一些，例如 `Java`、`JavaScript`、`Ruby`、`Python`、`C#`、`Go`、`Rust` 和 `Swift`。尽管每种语言看起来不同，但它们都致力于完成同一项任务：以一种比机器语言更友好、更易于管理的方式，帮助你与机器进行交互。事实上，大多数编程语言都围绕非常相似的概念设计，有些甚至外观相似。因此，学习任何一种编程语言都能帮助你更轻松地学习另一种编程语言。我很少招聘那些已经掌握我们团队所用编程语言的人。如果一个人学会了一门编程语言，并通过练习变得精通，那么学习一门新语言所需付出的努力就会相当少。

你可能会想，既然这些语言如此相似，为什么还有这么多编程语言可供选择？事实是，在工程设计中，必须做出权衡。有时，为了让某一类任务更简单，另一类任务就会变得更困难。在我的厨房里，既有搅拌机也有榨汁机。它们都基于相同的基本原理——将食物放入主容器，电机转动，然后某个附件将食物混合在一起。尽管这些任务非常相似且原理相同，但世界上的食物种类繁多，需要混合的方式也多种多样，因此搅拌机更适合某些任务，而榨汁机则适合其他任务。同样，对于编程语言，有些更适用于不同的任务。此外，编程语言的选择也取决于程序员。就像不同类型的汽车适合不同司机的偏好和驾驶习惯一样，不同的编程语言也适合不同类型的程序员的偏好和习惯。基于这些原因，几乎对于任何你想要完成的任务，都有众多的编程语言可供选择。

本书所介绍的编程语言是 `JavaScript`。我之所以喜欢将 `JavaScript` 作为第一门语言来教授，有几个原因。首先，`JavaScript` 最初就是被设计为一门入门级语言的。该语言的目标之一就是让新程序员能够快速上手。尽管 `JavaScript` 旨在让编程对新程序员更简单，但作为一种语言，它的功能并不逊色。其次，`JavaScript` 已成为网站界面的*事实标准*编程语言。如果你使用的网站除了链接到其他网页之外还有任何其他功能，那么很可能都涉及 `JavaScript`。因此，学习 `JavaScript` 将在理解 Web 运作方式方面立即带来实际好处。第三，编程 `JavaScript` 的工具在每台计算机上都可用。你不需要下载任何特殊工具来编写 `JavaScript` 程序。只要你的计算机上有网页浏览器，你就可以编写 `JavaScript` 程序！最后，`JavaScript` 与其他流行的编程语言（如 `C#`、`Java` 和 `Swift`）非常相似。因此，掌握 `JavaScript` 不仅对网站编程立竿见影，而且也是一种能让你轻松过渡到其他流行系统的语言。

## 本书面向编程初学者

无需任何编程经验。本书假设您已掌握电脑基本操作和互联网浏览技能，仅此而已！

您将不仅学到计算机编程基础，更会了解计算机与数据运作的通用知识。您将了解计算机的起源、工作原理、数据处理方式、数据传输机制以及网页运行原理。本书不会深入探讨所有这些主题，但会为您构建一个基础工作框架，帮助您更好地理解未来可能遇到的其他概念。

## 1.2 如何使用本书

本书采用若干规范助力您的编程之旅。首先，本书将介绍新术语。为突出重要词汇，术语在首次出现时将采用`粗体`印刷。附录 A 提供了完整术语列表。这些术语至关重要，请牢记其含义。

当本书列出计算机程序、程序片段或任何需要精确输入的内容时，会以特殊字体从正文中分离显示，帮助您识别这是计算机程序。计算机程序示例如下：

```
window.alert("这是一个计算机程序示例。");
```

此外，市面上存在多种类型的计算机，各自搭载不同版本的操作系统和软件。还有众多网页浏览器，功能各异且操作方式略有不同。本书将尽力指导您在每个操作系统上完成环境配置。若书中任何内容取决于您使用的特定操作系统或浏览器，附录 B 提供了包括 Windows 和 Mac 在内的多种系统操作步骤。届时本书会指引您查阅相应附录章节。尽管本书适用于任何现代浏览器（基本指 2008 年后发布的版本），但我推荐使用谷歌浏览器。截至撰写本文时，谷歌浏览器是程序员最易使用的浏览器。不过使用其他浏览器（包括 Brave、Firefox、Safari、Chrome、Opera 或 Edge）也完全可行。

本书包含多项练习题目和实践活动。这些题目和活动的目的在于提供动手实践方式帮助理解内容。通过完成练习，文本内容将更具意义且更易理解。更重要的是，它们可能揭示您对文本理解不透彻之处。许多人遇到理解困难时容易跳过内容。练习题目和活动让您有机会放慢脚步，确认哪些部分已掌握、哪些需要重读并深思。练习题层层递进，按顺序完成即可精准定位问题所在。

每章末尾设有回顾章节，总结该章最重要的概念。随后是帮助您练习应用知识的实践题目。这些题目要求您深入思考章节内容及其内涵。

附录 A 包含本书术语扩展词汇表，以及阅读编程资料时可能遇到的其他词汇。本章节将帮助您在阅读和与人讨论编程时找准方向。建议您阅读过程中，同步查阅词汇表中那些听过但当时未能理解的词汇。

此外，编写代码时若遇问题，附录 B.6 节提供了若干让您回归正轨的建议。
