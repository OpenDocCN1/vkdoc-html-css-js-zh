# 修饰符

可以为正则表达式添加不同的修饰符，以改变表达式的解释和执行方式。修饰符通常写在表达式结尾之后。

坏消息是，不同的正则表达式实现带有不同的修饰符。好消息是，在使用某种语言之前，你可以查找并熟悉该语言中可用的修饰符。

表 2-3 展示了一些修饰符的示例。

**表 2-3** 修饰符

| 修饰符 | 语义 |
| --- | --- |
| `g` | 全局匹配，在首次匹配后不会停止返回。 |
| `m` | 多行匹配，使`^`和`$`匹配行的起始和结束，而非整个字符串的起始和结束。 |
| `s` | 单行模式。字符`.`匹配所有字符，包括`\n`。 |
| `i` | 不区分大小写匹配。 |
| `x` | 忽略空白字符。此选项启用自由间距模式。 |
| `u` | 使用完整 Unicode 匹配。 |

这些标志并非通用。例如，`x`标志在 JavaScript 中不可用。`g`标志在 PHP 中不可用，因为全局模式只能通过调用不同的匹配器函数来访问。

让我们在 JavaScript 控制台中查看不区分大小写模式的效果：

```
> /re/.test( 'Regex' );
false
> /re/i.test( 'Regex' );
true
```

不区分大小写模式将字符串视为不区分大小写，使序列`Re`与正则表达式`/re/i`匹配。

目前，你可以认为`/re/i`与`/(r|R)(e|E)/`是等价的。这并不完全准确，原因有二，且会影响效率：

* 稍后你将学习一种更优的方式来表示字符集，例如表示集合`{r, R}`中的字符。

* 你将学习括号用于捕获子字符串的次要功能，这可能会大幅降低正则表达式的速度。

在本节中不必担心性能问题。重点在于掌握正确的语法。
