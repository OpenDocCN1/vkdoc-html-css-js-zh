# 后顾断言

*后顾断言*是前瞻断言的镜像。它从正则表达式的位置向后移动，检查指定模式是否匹配后顾断言*之前*的字符串。如果后顾断言匹配成功，则回退匹配。其语法如表 8-2 所示。

## 表 8-2 后顾断言语法

| 后顾断言类型 | PCRE 语法 | Perl 6 语法 |
| --- | --- | --- |
| 肯定型 | `(?<=pattern)` | `<?after pattern>` |
| 否定型 | `(?<!pattern)` | `<!after pattern>` |
| 单词边界 | `\b` | `<<` |

与前瞻断言不同，后顾断言结构通常受到限制。具体的限制因实现而异。

大多数方言只允许固定长度的模式，并排除重复修饰符和字符集。但这并非普遍规则，例如，Java 就允许固定范围的重复修饰符。

### 示例 3

使用 PCRE，在非空白字符序列中匹配 `list`、`lost`、`lust`，要求它们位于非空白字符序列的开头。

#### 解决方案：

这一次，单词边界锚点被放在匹配字符串的 `l` 之前。

```
PCRE:    /\bl[iou]st/
```
