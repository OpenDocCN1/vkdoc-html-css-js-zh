# 定位起始锚点和结束锚点

在某些方言（如 JavaScript）中，`^`和`$`符号表示待匹配字符串的起始和结束。而在其他环境（如 EMACS 和 VIM）中，`^`和`$`符号表示待匹配行的起始和结束。

## 在 BRE、ERE、多数基于 PCRE 的语言以及 Perl 6 中

* `/^x/` 匹配以`x`开头的字符串。
* `/x$/` 匹配以`x`结尾的字符串。
* `/^x$/` 匹配只包含字符`'x'`的字符串。

在某些基于 PCRE 的语言中，上述字符仅表示行的边界断言。例如在 Ruby 中：

* `/^x/` 匹配以`x`开头的行。
* `/x$/` 匹配以`x`结尾的行。
* `/\Ax/` 匹配以`x`开头的字符串。
* `/x\z/` 匹配以`x`结尾的字符串。

当`^`和`$`对行边界进行限制时，在多数基于 PCRE 的语言中，对于包含多行的字符串，你可以分别使用`\A`和`\z`或`\Z`字符。

这不是通用规则，因为在 JavaScript 中，`\A`表示字面字符`A`。JavaScript 使用单词边界断言`\b`来测试单词的起始或结束。

* `/\bx/` 匹配以`x`开头的单词。
* `/x\b/` 匹配以`x`结尾的单词。

此外，在 JavaScript 中，多行修饰符`m`会重新定义`^`和`$`，使其分别匹配行的起始和结束。你将在下一章学习多行修饰符。

## 在 EMACS 中

* ``/\`x/`` 匹配以`x`开头的字符串。
* `/^x/` 匹配以`x`开头的行。
* `/x\'/` 匹配以`x`结尾的字符串。
* `/x$/` 匹配以`x`结尾的行。

## 在 VIM 中

* `/\%^x/` 匹配以`x`开头的字符串。
* `/^x/` 匹配以`x`开头的行。
* `/x\%$/` 匹配以`x`结尾的字符串。
* `/x$/` 匹配以`x`结尾的行。

## 在 Perl 6 中

* `/^x/` 匹配以`x`开头的字符串。
* `/x$/` 匹配以`x`结尾的字符串。
* `/^^x/` 匹配以`x`开头的行。
* `/x$$/` 匹配以`x`结尾的行。

你可以得出结论：定位起始锚点和结束锚点字符在不同方言中的行为可能完全不同。在依赖这些断言前，务必查阅文档并测试你的代码。

### 练习 1

在 JavaScript 中，`/^list`|`lost`|`lust$/`会匹配以下哪些字符串？为什么？

* `list,`
* `lostlist,`
* `listlist,`
* `lustlist?`

### 解答

令人惊讶的答案是，前三个字符串都能匹配。以下是验证结果：

```
> 'list'.match( /^list|lost|lust$/ )
["list", index: 0, input: "list"]
> 'lostlist'.match( /^list|lost|lust$/ )
["lost", index: 0, input: "lostlist"]
> 'listlist'.match( /^list|lost|lust$/ )
["list", index: 0, input: "listlist"]
> 'lustlist'.match( /^list|lost|lust$/ )
null
```

你可能错误地认为该正则表达式只匹配字符串`'list'`、`'lost'`和`'lust'`，而非其他内容，因为字符串的起始和结束都被锚定了。

如果你期望只有`list`能匹配该正则表达式，请回忆选择运算一节中的内容：管道运算符在正则表达式中是所有运算符中优先级最低的。

`|`运算符优先级最低，这意味着`^`和`$`的绑定优先级更高。如果使用括号来突出自然优先级，你会得到以下表达式：

```
/(^list)|lost|(lust$)/
```

该表达式解读如下：匹配任何满足以下任一条件的字符串：

* 以`list`开头
* 包含`lost`
* 以`lust`结尾

第二个字符串`'lostlist'`能匹配，因为它包含`lost`。第三个字符串`'listlist'`能匹配，因为它以`list`开头。

第四个字符串`'lustlist'`不匹配，因为它不以`list`开头，不包含`lost`，也不以`lust`结尾。

如果你想将匹配范围限定为仅`list`、`lost`和`lust`，则必须使用括号。

```
/^(list|lost|lust)$/
```

添加括号后，只有第一个字符串能匹配该表达式。

```
> 'list'.match( /^(list|lost|lust)$/ )
["list", index: 0, input: "list"]
> 'lostlist'.match( /^(list|lost|lust)$/ )
null
> 'listlist'.match( /^(list|lost|lust)$/ )
null
> 'lustlist'.match( /^(list|lost|lust)$/ )
null
```

当将锚点字符与`|`一起使用时，务必使用括号标明你预期的优先级，即使你的意图显而易见，甚至括号的使用是冗余的。这样，你的表达式将更易于维护。
