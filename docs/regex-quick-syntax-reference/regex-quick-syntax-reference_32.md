# 在正则表达式中复用捕获子串

假设我们要提取被任意多个高亮字符包围的价格。以下字符串都应该能够匹配：

```
****€19.00****
*-*€19.00*-*
--€19.00--
```

以下输入则无效：

```
€19.00     // 没有高亮字符
*€19.00**  // 前后长度不匹配
**€19.00-- // 字符序列不匹配
++€19.00++ // 字符未被接受
```

假设价格范围在 `1.00` 到 `9999.99` 欧元之间，我们从组装正则表达式开始，如表 7-4 所示。

**表 7-4**
组装一个匹配价格标签的正则表达式

| 构建的正则表达式 | 说明 |
| --- | --- |
| `/^$/` | 我们要匹配整个字符串，而不仅仅是子串。 |
| `/^[\*-]+$/` | 我们从任意多个高亮字符开始。 |
| `/^[\*-]+`€`\.$/` | 我们在表达式中加入欧元符号和转义后的点字符。 |
| `/^[\*-]+`€`\d{1,4}\.\d{2}$/` | 然后添加数字，确保小数点后始终有两位数字。 |

现在我们陷入了困境。使用目前学到的构造方法，无法继续组装正则表达式。

这时，我们需要知道欧元符号之前精确匹配了什么内容。复用之前捕获的子串就派上用场了，如表 7-5 所示。

**表 7-5**
使用反向引用匹配价格标签

| 构建的正则表达式 | 说明 |
| --- | --- |
| `/^([\*-]+)`€`\d{1,4}\.\d{2}$/` | 捕获需要重复的子串 |
| `/^([\*-]+)`€`\d{1,4}\.\d{2}\1$/` | 使用 `\1` 访问并插入捕获组 `1` 中精确匹配的子串 |

让我们在 Chrome 开发者工具控制台中使用 JavaScript 测试这个正则表达式。

```
/^([\*-]+)€\d{1,4}\.\d{2}\1$/.exec( '****€19.00****' )
> {
0: "****€19.00****",
1: "****",
index: 0,
input: "****€19.00****"
}
```

`\1` 被称为*反向引用*。反向引用会重新匹配字符组中已经匹配过的相同字符。

**示例**：创建一个兼容 PCRE 的正则表达式，用于检测由四个字母组成的回文^(⁵⁰)单词。

**解决方案：**

我们需要使用常规的开始和结束锚点，后跟两个任意字符。由于需要捕获这些字符，我们将其放在括号中。然后，通过反向使用顺序，使用反向引用 `\2` 和 `\1` 来交换这些字符的位置。

```
/^(.)(.)\2\1$/
```

在 Perl 6 中，反向引用是通过在捕获组编号前加上 `$` 符号来定义的变量。示例如下：`$0`。

始终测试你的反向引用。当反向引用不存在时，错误行为会因环境而异。

## 捕获组与性能

不幸的是，括号的语义被重载了。这在性能方面可能很危险。

当我们学习正则表达式的基础知识时，我们了解到括号的自然语义是覆盖运算符的优先级。但是，请注意以下几点：

无论是否需要，每组括号都会创建一个捕获组。由于捕获组的开销较大，维护捕获组的额外开销会增加表达式的执行时间，从而影响正则表达式的性能。

维护捕获组的开销可能很大。在读取字符或进行回溯时，正则表达式引擎必须从活动捕获组中添加或删除字符。

为了避免性能损失，可以定义不创建捕获组的括号。这些括号仅用于覆盖优先级，如表 7-6 所示。

**表 7-6**
非捕获括号

| 语言 | 非捕获括号 |
| --- | --- |
| EMACS | `/(?:exp)/` |
| ERE, PCRE | `/(?:exp)/` |
| Perl 6 | `/ [exp] /` |
| VIM | `/\%(exp)/` |

在大多数编程语言和 EMACS 中，起始括号后的 `?:` 将组定义为非捕获组。在 Perl 6 中，早期语言的字符集语法被用于此目的。这是因为 Perl 6 是一种新语言，并且时间证明，相比字符集，我们更常需要非捕获括号。

VIM 提出了一些奇怪的符号，事后看来我觉得这些符号非常不合逻辑。但在这些符号被发明的时候，它们一定是非常创新的。

## 捕获组的扩展

一些基于 PCRE 的语言提供了更多功能。

Ruby 和 Perl 支持相对于当前捕获组的反向引用。语法因实现而异。Ruby 中的一个示例如 `((.)\k<-1>)+`，其中反向引用是 `\k<-1>`，表示该反向引用之前的捕获组。

在某些语言中，*前向引用*使得引用一个未来的捕获组成为可能。示例如下：`(\3\2(.)(.))*`。

捕获组编号的一个问题是可维护性。即使在提取之后，变量 `$1`、`$2` 等也不具有足够的语义。Python 通过在正则表达式中允许使用名称标签来解决这个问题。示例如下：`(?P<name>value)`。在 ES2018（2018 年版的 JavaScript）中，命名捕获组也以 `(?<name>value)` 的形式出现。

## 总结

在本章中，你学习了创建捕获组的基础知识，并了解了捕获组编号的规则。你还学会了在四种不同的语言中检索捕获的字符串。

由于捕获组的维护开销可能较大，你了解了定义非捕获括号以避免性能损失的方法。
