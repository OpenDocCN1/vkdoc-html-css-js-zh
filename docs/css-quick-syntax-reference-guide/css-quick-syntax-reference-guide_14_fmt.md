# 7. 特指度

当多个规则应用于同一个元素并且指定了相同的属性时，会有一个优先级方案来决定哪个规则优先。简而言之，CSS 会优先考虑选择器最具体的规则。

## 选择器特指度

计算特指度有一些基本规则。权重为 0 的最低特指度由通用选择器（`*`）赋予，它匹配文档中的所有元素。

```css
* { color: red; } /* 0 */
```

类型选择器的权重为 1，因此一个包含两个类型选择器的选择器，其特指度为 2。

```css
p { color: blue; } /* 1 */

body p { color: gold; } /* 2 */
```

类选择器的权重为 10，伪类和属性选择器也是如此。当这些选择器包含一个类型选择器时，总权重为 11。

```css
.a { color: lime; } /* 10 */

p:first-child { color: navy; } /* 11 */

p[class=a] { color: teal; } /* 11 */
```

伪元素不计入任何特指度，除非是伪元素前缀的选择器所增加的特指度。

```css
p:first-letter { color: white; } /* 1 */
```

ID 选择器的权重为 100，因此一个 ID 规则会覆盖大多数其他冲突样式。

```css
#i { color: aqua; } /* 100 */
```

内联样式的权重为 1000，甚至超过 ID 规则。

```html
<p style="color: black;">文本</p>
```

要覆盖所有其他冲突样式，包括定义为内联样式的样式，可以将声明声明为 `!important`。请注意，`!important` 修饰符应用于单个声明，而非整个规则。

```css
p { color: red !important; }
```

如果两个冲突规则之间的特指度相同，则由层叠决定应用哪个规则。

## 层叠

在 CSS 中，多个样式表可以影响文档的呈现。此特性被称为层叠（CSS 中的“C”代表层叠），因为浏览器会合并所有样式表以在应用样式之前解决任何冲突。

网页文档可以拥有来自三个不同来源的样式表：浏览器、网站设计者和阅读文档的用户。设计者的样式表通常具有最高优先级，其次是用户的个人样式表（如果有的话），然后是浏览器的默认样式表。

## 设计者样式

如前所述，网页设计者有三种方式包含 CSS 规则：内联样式、内部样式表和外部样式表。在这三者中，内联样式的优先级最高，其次是内部样式表，然后是外部样式表。

如果网页包含多个具有冲突规则（相同特指度）的外部样式表，则 HTML 标记中最后包含的样式表具有更高的优先级。在样式表内部也是如此。如果选择器相同，最后声明的属性才生效。

```css
p { color: orange; } /* 被覆盖 */

p { color: silver; } /* 主导 */
```

对于继承的样式，元素自身的样式优先级高于从其祖先继承的样式。

```css
p { color: orange; } /* 主导 */

body { color: silver; }
```

## 特指度指南

如本章所示，元素的样式可以在许多不同的位置以不同的优先级指定。层叠特性赋予了 CSS 很大的灵活性，但如果管理不当，也可能导致不必要的复杂性。

通常，您希望保持较低的特指度，以便更容易了解哪些规则会优先。这样，您可以通过调整样式规则出现的顺序来利用层叠机制，而不是通过使用 ID 和 `!important` 来不必要地增加特指度以覆盖冲突样式。
