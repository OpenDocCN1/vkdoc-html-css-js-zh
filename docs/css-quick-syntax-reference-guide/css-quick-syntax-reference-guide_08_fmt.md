# 类选择器与 ID 选择器

类选择器和 ID 选择器定义的规则仅适用于选定的 HTML 元素集。它们允许你标识单个元素或元素组，而无需为元素类型的所有实例设置样式。

## 类选择器

类选择器用于标识一组元素。它通过句点符（`.`）后跟类名来识别。类可以是可应用于任何元素的通用类。

```css
/* 选择任何类名为 myclass 的元素 */
.myclass {}
```

选择器也可以是一个只能应用于一种元素类型的特定类。特定类通过在句点符前声明元素名称来定义。

```css
/* 选择任何类名为 myclass 的 <p> 元素 */
p.myclass {}
```

特定类使得标识类在何处使用更加容易；通用类则允许更大的代码复用性。

### 类示例

例如，假设某些元素内的文本需要着色，但不是所有该元素实例都需要。第一步是添加一个指定了颜色属性的通用类规则。

```css
.info { color: green; }
```

该规则规定，任何 `class` 属性值为 `"info"` 的元素都将采用此样式。

```html
<p class="info">绿色</p>
```

如果某个类规则只被一种元素类型使用，它可以被定义为特定类。这样做能让阅读样式表的任何人更容易理解该样式用于何处。

```css
p.warn { color: orange; }
```

特定类规则与通用类规则以相同方式应用于文档，但它只会为指定类型的元素设置样式。

```html
<p class="warn">橙色</p>
```

通过用空格分隔每个类名，可以将多个类规则应用于单个元素，这使得类规则非常灵活。

```html
<p class="style1 style2"></p>
```

## ID 选择器

ID 选择器用于标识单个唯一元素。虽然它的工作方式与类选择器非常相似，但它使用的是井号符（`#`）而不是句点符，并且使用的是 `id` 属性而不是 `class` 属性。与 `class` 属性一样，`id` 是一个通用属性，可以应用于几乎任何 HTML 元素。它为文档中的元素提供了唯一标识符。

```css
/* 选择 id 设置为 myid 的元素 */
#myid {}
```

与类选择器一样，ID 选择器可以通过元素进行限定。但是，由于一个给定 ID 应该只有一个元素，这种额外的限定通常被认为是不必要的。

```css
/* 选择 id 设置为 myid 的 <p> 元素 */
p#myid {}
```

### ID 示例

以下 ID 选择器将匹配文档中 `id` 属性设置为该 ID 的唯一元素。因此，如果样式意图只应用于单个元素实例，可以使用此选择器代替类选择器，因为这能更清晰地表明规则的使用位置。

```css
#err { color: red; }
```

ID 规则通过使用 `id` 属性应用于元素。由于 `id` 属性必须唯一，每个 ID 选择器在每个网页上只能用于一个元素。因此，ID 选择器隐式地指定了该样式在任何页面上只使用一次。

```html
<p id="err">红色</p>
```

## 类与 ID 使用指南

在许多情况下，使用类是 CSS 中选择元素的首选方法，因为类既灵活又可复用。另一方面，ID 通常用于网站的结构元素，例如 `#content` 和 `#footer`，以突出这些元素具有独特作用。
