## 2. 分组

为了使样式表简短且易于编辑，相似的规则可以组合在一起。这种分组提供了几种指定一组相关规则的方法。例如，您可以通过以下各节描述的四种不同方式为两个标题元素设置文本为红色、背景为黑色。

### 未分组的规则

每个规则可以单独编写，这允许您对每个选定的元素应用单独的样式规则。

```
h1 { color: red; }
h1 { background: black; }
h2 { color: red; }
h2 { background: black; }
```

### 分组选择器

可以将选择器用逗号分隔来进行分组。这种分组将使声明应用于多个选择器。

```
h1, h2 { color: red; }
h1, h2 { background: black; }
```

### 分组声明

可以将声明用分号分隔来进行分组。声明块内的所有样式都将应用于选择器。

```
h1 {
  color: red;
  background: black;
}

h2 {
  color: red;
  background: black;
}
```

### 分组选择器和声明

可以同时组合选择器和声明，从而形成一个单独的规则。

```
h1, h2 {
  color: red;
  background: black;
}
```

应尽可能地对规则进行分组，以使代码更加简洁。它具有性能优势，因为简洁的规则减小了样式表的大小，从而使 `CSS` 文件加载更快。此外，将属性仅指定在一个地方也很方便，以防将来需要修改它们。另外，对具有相似样式的选择器进行分组有助于更容易地在它们之间保持一致性。
