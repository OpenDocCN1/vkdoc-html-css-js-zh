# 9. 单位

在指定属性值的大小时，有多个单位可供选择。

## 绝对单位

长度的绝对单位包括厘米（`cm`）、毫米（`mm`）和英寸（`in`）。尽管这些单位旨在不论屏幕分辨率如何都保持一致的外观，但实际情况并非总是如此，因为浏览器并不总能获知显示介质的精确物理尺寸。

```css
.one-cm { font-size: 1cm; }
.one-mm { font-size: 1mm; }
.one-in { font-size: 1in; }
```

当输出介质的尺寸已知时（例如用于打印到纸张的内容），这些单位非常有用。不建议在屏幕显示中使用这些单位，因为屏幕尺寸可能差异很大。

## 印刷单位

点（`pt`）和派卡（`pc`）是印刷单位。根据定义，1 英寸等于 72 点，1 派卡等于 12 点。与绝对单位类似，印刷单位最适用于打印样式表，而非屏幕显示。

```css
.one-point { font-size: 1pt; }
.one-pica  { font-size: 1pc; }
```

## 相对单位

长度的相对单位包括像素（`px`）和百分比（`%`）。百分比是与该属性父元素值成比例的单位；像素相对于所用显示设备上的物理像素而言。

```css
.one-pixel   { font-size: 1px; }
.one-percent { font-size: 1%; }
```

对于屏幕显示而言，像素和百分比是 CSS 中最有用的两种单位。像素是固定尺寸的，因此可以非常精确地控制网页文档中的布局。另一方面，百分比对于定义文本内容的字体大小非常有用，因为文本保持可缩放性，这对于小屏幕设备和无障碍访问非常重要。当文本是设计的一部分且需要与其他元素匹配时，可以使用像素来设置尺寸，以获得更好的控制。现代浏览器都支持整页缩放，这使得基于像素的字体大小更易被接受。请注意，对于高分辨率屏幕，一个 CSS 像素会渲染为多个屏幕像素。例如，Apple Retina 显示屏会将所有像素尺寸以实际大小的两倍进行渲染。

## 字体相对单位

另外两个相对度量单位是 em 高度（`em`）和 ex 高度（`ex`）。Em 高度与字体大小相同；ex 高度约为字体大小的一半。

```css
.one-ex { font-size: 1ex; }
.one-em { font-size: 1em; }
```

与百分比类似，em 高度是一种良好的相对单位，常用于设置网页文档文本的字体大小。两者都尊重用户在浏览器中选择的字体大小，并且在小屏幕设备上比基于像素的字体大小更易于阅读。

CSS 3 引入了两个额外的字体相对单位：`rem` 和 `ch`。根 em 高度（`rem`）单位相对于根元素（`<html>`）的字体大小。它可以用来替代 `em`，以防止元素的字体大小受到其祖先元素字体大小变化的影响。

```css
.one-rem { font-size: 1rem; }
```

字符单位（`ch`）测量元素字体中字符零（0）的宽度。该单位非常适用于定义包含文本的盒子的宽度，因为它大致对应了该盒子内能容纳的字符数量。

```html
<!-- 相同宽度 -->
<div style="width: 5ch;"></div>
<div>00000</div>
```

`ch` 单位仅受 Chrome 27+、Firefox 19+ 和 IE9+ 支持，因此应仅在提供备用方案的情况下使用。`rem` 单位的支持稍好一些，适用于 Chrome 4+、Firefox 3.6+、IE9+、Safari 4.1+ 和 Opera 11.6+。

## 视口单位

视口宽度（`vw`）和视口高度（`vh`）单位允许元素相对于视口（即可见的文档部分）来设置尺寸。每个单位代表当前视口的一个百分比值。

```css
width:  50vw; /* 视口宽度的 50% */
height: 25vh; /* 视口高度的 25% */
```

另外两个视口单位是 `vmin` 和 `vmax`，分别给出视口尺寸的最小值或最大值。

```css
width:  1vmin; /* 1vh 或 1vw，取较小值 */
height: 1vmax; /* 1vh 或 1vw，取较大值 */
```

Chrome 26+、Firefox 19+、IE11+、Safari 6.1+ 和 Opera 15+ 均支持视口单位。`vh`、`vw` 和 `vmin` 单位的支持范围比 `vmax` 更广，可追溯到 Chrome 20+、IE9+ 和 Safari 6.0。在 IE9 和 IE10 中，`vmin` 被称为 `vm`。

## 单位值

可以使用小数来设置长度。某些属性也允许长度为负值。

```css
p { font-size: 0.394in; } /* 小数值 */
p { margin: -1px; } /* 负值 */
```

请注意，如果单位前有空格或未指定单位（零值除外），则规则无效。在零后包含单位是可选的，但省略它是一种良好的做法。

```css
p { font-size: 1ex; }  /* 正确 */
p { font-size: 0; }    /* 正确 */
p { font-size: 0ex; }  /* 正确 */
p { font-size: 1 ex; } /* 无效 */
p { font-size: 1; }    /* 无效 */
```

当 CSS 声明包含错误时，浏览器会忽略它。规则中的其他有效声明仍然生效。
