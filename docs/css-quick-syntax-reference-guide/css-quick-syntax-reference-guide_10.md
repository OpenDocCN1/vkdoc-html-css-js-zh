# 10. CSS 属性

本书的其余章节将介绍 CSS 中可用的众多属性。在这些章节中，将使用形式化表示法给出可能的属性值，如下所示：

```
text-shadow : inherit | none | <offset-x> <offset-y> [<blur-radius>] [<color>]
```

这种表示法意味着 `text-shadow` 属性可以有三种不同类型中的一种值。默认值列在首位；这里默认值是 `inherit`。由于 `inherit` 关键字可为任何属性设置，除非它是默认值，否则不包含在内。第二个值 `none` 也是一个关键字。它是此属性的初始值，可用于禁用继承的属性效果。

该表示法中的第三个选项包含一组四个值——两个必需值，两个可选值——如方括号（`[]`）所示。尖括号（`<>`）表示它们不是关键字；它们是其他值类型。在此示例中，它们是三个长度值和一个颜色值。遵循此表示法，以下声明展示了 `text-shadow` 属性的一个有效示例用法：

```
text-shadow: 1px 1px 1px red;
```

## 通用关键字

除了 `inherit`，你在 CSS 中可能还会遇到另外两个通用属性关键字：`initial` 和 `unset`。这两个通用关键字均在 CSS 3 中引入，并且可以设置在任何属性上。

`initial` 关键字将属性的初始值（由 CSS 规范定义）应用到元素上。该关键字在 Chrome 1+、Firefox 19+、Safari 1.2+ 以及 Opera 15+ 中受到支持，但目前在任何版本的 IE 中均不受支持。由于缺乏 IE 支持，此关键字的实用性有限。建议显式地为特定属性指定其初始值以进行重置。

第三个通用关键字是 `unset`，它是 `initial` 和 `inherit` 关键字的组合。如果属性有继承值，它会将属性重置为其继承值；否则，它会将属性设置为初始值。目前，对 `unset` 关键字的支持仅限于 Firefox 27+。在所有主流浏览器支持此关键字之前，不应使用它。

## 怪异模式

当 HTML 和 CSS 被万维网联盟（W3C）标准化后，网页浏览器不能简单地遵从标准，因为这样做会破坏大多数已存在的网站。浏览器转而创建了两种独立的渲染模式：一种用于符合标准的新网站，另一种用于旧的遗留网站（怪异模式）。

在标准模式下，浏览器会尽力根据 HTML 和 CSS 规范来渲染页面。浏览器使用 `doctype`（文档类型声明）的唯一目的就是决定采用标准模式还是怪异模式。在网页文档开头处使用有效的 `doctype`（例如下面看到的 HTML 5 doctype）可以确保页面以标准模式渲染：

```
<!DOCTYPE html>
<html> ... </html>
```

这个 `doctype` 会触发所有主流浏览器（甚至可以追溯到 IE6）的标准模式。

## 供应商前缀

许多浏览器在某个新 CSS 属性的规范稳定之前，就早早地开始引入该属性。因为这些实现是实验性的，所以它们的属性名称包含一个供应商前缀，以表明该规范将来可能会发生变化。

主要的供应商前缀包括：用于 Firefox 的 `-moz`；用于 Internet Explorer 的 `-ms`；用于 Opera 的 `-o`；以及用于 Chrome、Safari、Android 和 iOS 的 `-webkit`。最近的 Opera 版本也与 `-o` 前缀并行实现了 `-webkit` 前缀。例如，可以通过使用以下供应商前缀来提高对 CSS 3 `border-radius` 属性的支持。注意，无前缀版本应始终放在最后。

```
.round {
  /* Safari 3-4, iOS 1-3.2, Android 1.6-2.0 */
  -webkit-border-radius: 3px;
  /* Firefox 1-3.6 */
  -moz-border-radius: 3px;
  /* Opera 10.5+, IE9+, Safari 5+, Chrome 1+,
     Firefox 4+, iOS 4+, Android 2.1+ */
  border-radius: 3px;
}
```

随着时间的推移，新属性的规范会变得稳定，浏览器会逐渐放弃供应商前缀。再过一段时间，网络用户会放弃旧浏览器转而使用新版本，对供应商前缀的需求便会减少。`border-radius` 属性已经经历了这个过程，现在鼓励开发者弃用这些前缀，以便让全世界的 Web 开发者更轻松一些。

## 渐进增强

在决定是否使用最新的 CSS 特性时，重要的是要考虑没有它时你的网站会是什么样子。如果该特性能够增强你网站的外观（例如 CSS 3 的 `border-radius` 属性），你可能会想开始使用它，即使只有一小部分访问者能看到它。时间会站在你这一边，随着人们抛弃旧浏览器，越来越多的访问者能够看到这个特性，从而增强他们在你网站上的体验。这就是渐进增强的本质。

另一方面，如果你的网站依赖该特性，而没有它时网站看起来会出问题，那么你需要仔细考虑该特性的支持程度，以及是否有你可以利用的后备方案或脚本来提高支持率，例如 HTML5 Polyfills 网站上列出的那些。¹ 在 CSS 中实现相同效果的方法通常有很多种，因此为网站的关键元素（如布局）选择一种所有主流浏览器都很好支持的方法是一个好主意。
