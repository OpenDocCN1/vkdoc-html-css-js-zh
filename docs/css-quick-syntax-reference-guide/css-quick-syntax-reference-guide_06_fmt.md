# 1. 使用 CSS

将 CSS 插入 HTML 文档有三种方式：使用内部样式表、内联样式或外部样式表。内部样式表适用于单个页面，内联样式适用于单个元素，而外部样式表则可能应用于整个网站。

## 内部样式表

当单个文档需要拥有自己独特的样式时，内部样式表非常有用。该样式表通过`<style>`元素嵌入到网页文档的`<head>`部分中。此元素是样式表规则的容器，且应将其`type`属性设置为`"text/css"`。

```
<style type="text/css">
  p { color: red; }
</style>
```

## 内联样式

可以通过使用`style`属性为单个元素分配样式，从而设置内联样式。它是一个通用属性，可包含在任何 HTML 起始标签中，其值是将应用于该元素的 CSS 声明，这些声明之间用分号隔开。无需指定选择器，因为这些声明隐式地属于当前元素。

```
<p style="color: green">Green text</p>
```

这种方法应谨慎使用，因为它将样式与内容混合在一起，从而使得未来的修改更加繁琐。在将样式移出到外部样式表之前，它作为一种快速测试样式的方法很有用。

## 外部样式表

包含 CSS 最常见的方式是通过外部样式表。样式表规则被放置在一个扩展名为`.css`的独立文本文件中。然后，通过网页头部中的`<link>`元素来引用此样式表。`rel`（关联）属性必须设置为`"stylesheet"`，并且`type`属性可以（可选地）设置为`"text/css"`。样式表的位置通过`href`属性指定。

```
<link rel="stylesheet" type="text/css" href="MyStyle.css">
```

另一种不太常见的包含外部样式表的方式是在`<style>`元素内部使用 CSS 的`@import`函数。为了使此函数生效，它必须放置在任何其他规则之前。

```
<style type="text/css">
  @import url("MyStyle.css");
</style>
```

使用外部样式表通常是首选，因为它将 CSS 与 HTML 文档完全分离。这样一来，就可以快速为整个网站创建一致的外观，并且只需编辑一个 CSS 文档即可更改其外观。它还具有性能优势，因为外部样式表会被缓存，因此只需下载一次——即在访客浏览您网站的第一个页面时。

### 测试环境

为了实验 CSS，您可以使用简单的文本编辑器，例如 Windows 中的记事本（位于“开始 ➤ 程序 ➤ 附件 ➤ 记事本”）或 Mac 上的文本编辑（位于“访达 ➤ 应用程序 ➤ 文本编辑”）。在编辑器中新建一个文档，并键入下面这条单独的样式规则。该规则会将网页文档的背景颜色变为红色。

```
body { background: red; }
```

将文件保存为`MyStyle.css`，然后打开另一个空白文档。这个新文档将成为使用您刚刚创建的外部样式表的 HTML 文件。在该文档中写入以下 HTML 标记，其中包含对样式表的引用以及 HTML 5 网页文档所需的最少标记：

```
<!DOCTYPE html>
<html>
  <head>
    <meta charset="UTF-8">
    <title>示例</title>
    <link rel="stylesheet" href="MyStyle.css">
  </head>
  <body>
    <p>此页面是红色的</p>
  </body>
</html>
```

继续操作，将此文本文件保存为`MyPage.html`，放到与 CSS 文件相同的文件夹中。至此，您已经创建了一个可以测试 CSS 的简单环境。要查看页面，请使用您的网络浏览器打开`MyPage.html`。您将会看到背景确实因样式表中的规则而变为红色。

## 查看源代码

当浏览器处于打开状态时，您可以通过在 PC 上按`Ctrl+U`或在 Mac 上按`Cmd+U`来查看构成页面的 HTML 标记。这个快捷键在所有主流浏览器中都有效，包括 Chrome、Firefox 和 Internet Explorer (IE)。您也可以通过右键点击页面并选择“查看源代码”来找到查看源代码窗口。在 Firefox 和 Chrome 中，样式表是可点击的，允许您查看应用于网页的外部样式表规则。（请注意，在 Chrome 中，您需要右键点击样式表并选择打开它，因为这个文件存储在您的本地机器上。）

像这样查看网页的源代码是向其他 Web 开发者学习的好方法。每当您在网页上发现一个有趣的元素——无论它是用 HTML、CSS 还是 JavaScript 创建的——页面源代码都会揭示它是如何创建的。

## 注释

CSS 中的注释是通过使用 C 风格的符号（`/* */`）创建的。放置在`/*`和`*/`之间的所有内容都会被浏览器忽略，即使分隔符跨越多行。

```
/* 多行
   注释 */
```

注释的主要用途是向开发者（包括未来的您）阐明代码。它们也可以通过划分样式表的不同区域或提供关于文件的元数据（例如作者姓名）来提高可读性。

```
/*
* 元数据
*/

/*** 部分标题 ***/
p { margin-top: -1px; } /* 说明 */
```

注释对于临时停用声明或整个样式规则以进行测试也很有用。

```
p { /* color: white; */ }
```

## 空白

空白指的是空格、制表符和换行符。您可以自由地使用空白来格式化您的样式表，使其更易于阅读。一种常见的格式化惯例是将声明拆分成多行。

```
.fruit {
  color: red;
  margin: 1px;
}
```

另一种流行的惯例是将规则的声明保留在一行中，只有当声明过多时才将它们拆分成多行。

```
.fruit       { color: red;   margin: 1px; }
.fruit.apple { color: green; margin: 2px; }
```

您使用的格式取决于个人偏好。选择对您有意义的方式，并力求保持一致。
