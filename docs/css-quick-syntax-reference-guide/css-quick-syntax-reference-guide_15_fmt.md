# 8. 颜色

在 CSS 中，有几种不同的方法可以指定颜色，以下各节将进行描述。

## 命名表示法

只需键入该颜色的通用名称即可设置颜色。

`p { color: red; } /* 将段落颜色设置为红色 */`

HTML 和 CSS 颜色规范包含了 140 个预定义的颜色名称，例如 `white`、`lime` 和 `olive`。这些颜色都得到了主流浏览器的支持。

## 十六进制表示法

对于完整的调色板，可以分别设置颜色的红色、绿色和蓝色分量。每个颜色分量由一个两位十六进制数组成，整个六位数前面加上一个井号（`#RRGGBB`）。十六进制意味着基数为 16 的计数，因此有效数字是 0 到 9 以及 A 到 F。每个红-绿-蓝对的取值范围可以从 00 到 FF，即十进制表示法中的 0-255。总共有 1600 万种可用颜色。

`p { color: #FF0000; } /* 红色:255, 绿色:0, 蓝色:0 */`

尽管这种颜色表示法是最晦涩的，但它也是最常见的，因为它精确、简洁且浏览器支持良好。发现颜色十六进制值的一个简单方法是使用图形软件（如 Adobe Photoshop 或 Paint.NET）中的取色器工具。

## 短十六进制表示法

十六进制表示法有一种短形式，其中颜色仅使用三位十六进制数字而不是六位数字来指定。通过将每个数字重复一次，可以将这种表示法转换为十六进制表示法。

`p { color: #f00; } /* 等同于 #ff0000 */`

当不需要长十六进制表示法提供的完整精度时，短十六进制表示法是一种有用的快捷方式。

## RGB 表示法

`rgb()` 函数允许将颜色值指定为红色、绿色和蓝色颜色分量的三个强度值。该值可以是 0 到 255 之间的整数，也可以是百分比。

`p { color: rgb(255, 0, 0); }`

`p { color: rgb(100%, 0%, 0%); }`

RGB 表示法允许与十六进制表示法相同的颜色精度。使用哪种表示法取决于个人偏好，但十六进制表示法通常更受青睐，因为它更短，并且可以轻松地从图像编辑器中复制，例如。

## RGBA 表示法

CSS 3 引入了 RGBA 表示法，增加了一个用于指定颜色透明度的 alpha 值。该 alpha 值为介于 0.0（完全透明）和 1.0（完全不透明）之间的数值。

```
/* 红色，透明度 50% */
p { color: rgba(100%, 0%, 0%, 0.5); }
```

Chrome、Firefox 3+、IE9+、Safari 和 Opera 10+ 均支持 RGBA 颜色值。若浏览器不支持，该规则将被忽略，因此可以像下方示例这样设置一个备用颜色值：

```
p {
  color: rgb(100%, 0%, 0%); /* 备用值 */
  color: rgba(100%, 0%, 0%, 0.5);
}
```

不支持 RGBA 的浏览器会忽略第二条声明，继续应用不透明版本的颜色。

## HSL 表示法

颜色值可以通过 `hsl()` 函数来设置（该名称代表色相、饱和度和明度）。色相是色环上从 0 到 360 的角度值，其中 0 和 360 为红色，120 为绿色，240 为蓝色。饱和度以百分比表示，0% 为灰色，100% 为纯色。明度同样以百分比表示，范围从 0%（黑色）到 100%（亮色）。

```
p { color: hsl(0, 100%, 100%); }
```

尽管 HSL 颜色比 RGB 颜色更直观，颜色值也更容易调整，但在 IE8 的使用率下降到网站无需再支持它之前，不应使用 HSL。HSL 属于 CSS 3 中的值，受 Chrome、Firefox、IE9+、Safari 和 Opera 10+ 支持。

## HSLA 表示法

与 RGB 类似，HSL 表示法也可以扩展一个用于指定透明度的 alpha 值。

```
/* 红色，透明度 50% */
p { color: hsla(0, 100%, 100%, 0.5); }
```

Chrome、Firefox 3+、IE9+、Safari 和 Opera 10+ 均支持 HSLA，这与 RGBA 函数的支持情况相同。
