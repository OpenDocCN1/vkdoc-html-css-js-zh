# 美观的排版

作为 Web 开发者，你很快就会在工作中发现，需要以自定义字体或公司专用字体（即终端用户计算机上预装的标准字体集之外的字体）来格式化某些文本。届时你需要决定如何以最佳方式显示这种风格化的文本。本章将介绍多种解决此问题的方案。我们将从开发便捷性、可维护性、可访问性、性能和视觉效果等方面，审视每种方法的优缺点。

### 挑战

在开始编码之前，让我们花点时间审视一下字体的具体构成。

### 字体的基本解剖结构

图 6-2 展示了一个字体的组成部分以及用于描述它们的术语。从底部看，*基线*是一条假想线，大部分字符都坐落在这条线上。从基线开始，字符向上延伸到*中线*，即基线之上标记大部分字符顶部的线条。基线与中线之间的距离称为*x 高度*，更常见的叫法是*字号*。

某些字符，包括大写字母以及小写字母 *b*、*d*、*f* 等，其部分结构会高于中线。字符位于中线上方的这部分被称为*上升部*。相反，某些字符（如 *g* 和 *j*）有一部分位于基线下方，称为*下降部*。

字距调整指的是单个字母之间的间距。一行的基线与下一行的中线之间的距离称为*行距*，即文本行之间的间距。

表 6-1 展示了这些字体术语如何对应到 CSS 样式属性。请注意，基线、中线、上升部和下降部的位置是由字体本身决定的，无法通过 CSS 改变。因为这样做会严重改变字体在页面上的外观，导致其在任意方向上不成比例地拉伸。

**表 6-1.** *字体 CSS 样式属性*

| **字体术语** | **CSS 样式属性** |
|---|---|
| X 高度（字号） | `font-size` |
| 字距调整 | `letter-spacing` |
| 行距 | `line-height` |

现在，让我们来看一些在页面上使用自定义字体渲染文本的不同技术。

### 使用静态图片显示文本

许多开发者在初次尝试自定义字体时，会使用 Adobe Photoshop 等图形程序为要显示的文本标题创建一个平面图片文件。然后将此图片作为前景图像引用到页面内的 `<img>` 标签中，标题文本则位于 `<img>` 标签的 `alt` 属性内，如下所示：

```html
<h1><img src="heading-news.png" alt="新闻" /></h1>

<h2><img src="heading-new-product.png" 
     alt="新产品发布：人类传送器" /></h2>
```

这是一种让风格化标题快速简单地显示在页面上的方法。然而，这种方法在可维护性和可访问性方面存在一些局限性。
