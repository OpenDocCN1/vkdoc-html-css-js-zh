亲爱的读者，

许多人熟悉富互联网应用程序（RIA），那些模糊了桌面软件与网页浏览器界限的网站。像网页邮件客户端、照片编辑器以及社交网络这类应用就跨越了这一界限。它们以直观、用户友好的界面为特色，无需页面刷新或中断最终用户体验。人们普遍认为，这类网站将越来越受欢迎。

我写这本书是为了帮助那些具备一定 `JavaScript` 技能的网页开发者，成功地创建他们自己专业、视觉丰富、动态且性能优化的 RIA。遵循本书中的指南，你可以放心地知晓你的代码是按照最佳实践构建的，并遵循了网络标准和可访问性指南。

在本书中，我将展示如何为你的 RIA 构建一个坚实、可维护的基础，包括 `HTML`、`CSS` 和 `JavaScript` 代码，以及实现浏览器与 Web 服务器后台动态通信所需的 `Ajax` 技术。我将描述在构建 Web 应用时可能遇到的性能限制以及如何最好地克服它们。我还将为你提供一些技巧，让你的用户界面感觉响应更快，即使你无法绕过这些性能限制。

你还将学习如何通过使用自定义字体添加排版标题、多媒体播放组件、自定义表单控件以及动态图表功能来改进你的 RIA 用户界面。此外，我将演示当与服务器的连接断开时，如何继续运行你的 Web 应用，如何使用 `Ajax` 读取存储在二进制文件中的隐藏数据，以及如何确保你的 `JavaScript` Web 应用具有最高级别的可访问性。

*将你的 `JavaScript` 知识转化为美观、动态且性能优化的富互联网应用程序*
