## 关于技术审校者

## 库纳尔·米塔尔

**库纳尔·米塔尔**担任索尼影视娱乐有限公司技术执行总监，负责 `SOA` 与身份管理项目。他为不同业务线提供集中化工程服务，并就内容管理、协作及移动战略提供咨询。

作为企业家，库纳尔常协助初创企业制定技术战略、产品路线图与开发计划。凭借与全球多家开发合作伙伴的深厚关系，他能够帮助初创企业乃至大型企业建立合适的开发伙伴关系。他通常以顾问或代理首席技术官的身份工作，并积极参与项目管理和技术架构职能。

库纳尔撰写并编辑了多本关于 `J2EE`、`WebLogic` 和 `SOA` 的著作与文章。他拥有软件工程硕士学位，也是一名持有仪表等级的私人飞行员。
