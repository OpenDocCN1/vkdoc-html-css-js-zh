# 第三章

## 理解网页浏览器

网页浏览器扮演着协调者的角色——为最终用户下载、渲染并执行你的网页应用。浏览器有能力让简单的代码看起来像一本光鲜的杂志文章（以苹果公司的 Safari 浏览器为例），或者像没有任何图片或高级功能的纯文本（以开源浏览器 Lynx 为例，可从`lynx.isc.org/`获取）。

本章将解释网页浏览器如何在内部运作，根据你编写的代码将用户看到的页面组合起来。同时，它也会描述网页如何通过网络连接到达你的浏览器，并指出若干可能阻碍性能的关键问题。

### 引擎：浏览器核心动力

在深入探讨浏览器内部工作原理之前，你需要了解一个重要区别：网页浏览器的用户界面与它在后台运行的代码之间的区别。让我们用汽车来类比。汽车引擎决定了它是一辆动力强劲还是高效节能的车。车身可能外观优美、设计精良，在静止时固然出色，但当你试图准时从 A 点到达 B 点时，它就没什么用处了。就像车身一样，设计精良的网页浏览器用户界面很少反映其内部运作。而如同引擎之于汽车引擎盖下，浏览器后台代码承担了繁重的工作。事实上，这些代码也被称为浏览器的*引擎*。

#### 渲染引擎与 JavaScript 引擎

大多数浏览器内部由两个主要引擎构成：

- 渲染引擎（也称为布局引擎），负责将 HTML 和 CSS 转换为屏幕上可见的页面
- `JavaScript`引擎，负责将你编写的`JavaScript`代码解释为浏览器能够理解并执行的内容

这些内部引擎与浏览器的用户界面是分开的。由不同公司、组织和个人编写的不同引擎，本质上决定了不同浏览器之间显示网页的差异。由于引擎与用户界面分离，从技术上讲，两个外观完全不同的网页浏览器可能使用相同的渲染引擎和`JavaScript`引擎。用户界面可以被视为包裹引擎的“皮肤”。事实上，有些网页浏览器基于相同的渲染引擎构建，如表 3-1 所示。

`表 3-1. 网页浏览器及其关联的渲染引擎`

| 渲染引擎 | 网页浏览器 |
|------------------|-------------|
| Trident | 微软 Internet Explorer |
| Gecko | Mozilla Firefox |
| Presto | Opera 浏览器 |
| WebKit | 苹果 Safari（含 iPhone）、谷歌 Chrome、诺基亚（移动设备） |

表 3-2 列出了主要的`JavaScript`引擎及使用这些引擎的部分浏览器。请注意，同一浏览器中可组合使用不同的渲染引擎和`JavaScript`引擎，因为两者是相互独立的，谷歌 Chrome 和 Safari 在实际应用中就证明了这一点。

`表 3-2. 网页浏览器及其关联的 JavaScript 引擎`

| `JavaScript`引擎 | 网页浏览器 |
|-------------------|-------------|
| JScript | 微软 Internet Explorer |
| SpiderMonkey | Mozilla Firefox（至 3.5 版本含） |
| TraceMonkey | Mozilla Firefox（3.6 版本） |
| `JavaScriptCore` | 苹果 Safari（至 3.2 版本含） |
| Nitro | 苹果 Safari（4 版本） |
| V8 | 谷歌 Chrome |
| Futhark | Opera |

随着更大、更复杂的`JavaScript`驱动的 RIA 被开发并在网上提供，浏览器引擎需要能够将它们解读为用户可访问的内容。`JavaScript`引擎开发者致力于改进软件，以宣称自己的产品是市场上最快、最高效的浏览器。这些开发者的实际目标是确保最终用户体验 RIA 时，能获得类似桌面应用的体验。从许多方面来看，浏览器正在成为新的操作系统。诸如加载时间过长、浏览器卡顿以及用户操作响应缓慢等负面体验正慢慢成为过去。

#### `JavaScript`引擎性能基准测试

让我们回到汽车的比喻。正如你所料，并非所有引擎都生而平等。有些引擎比另一些更高效；有些对资源（内存空间、磁盘空间等）的需求更高；有些则速度更快。就像用数据、图表和原始数据来比较不同车型和制造商的表现与效率一样，在网页浏览器领域也有类似的比较。性能基准测试很常见，其测试结果备受网页开发者的关注。

这类比较存在一些争议，因为许多制造商会选择推广对自己产品有利的基准测试结果。这意味着，要全面了解性能全貌，需要警惕并仔细审视测试结果。

在撰写本书时，有四个主要的`JavaScript`基准测试套件被广泛用于比较不同浏览器中不同`JavaScript`引擎的性能：

- **SunSpider**：由 WebKit 引擎开发团队创建，是目前最常用的`JavaScript`性能基准测试套件。其测试仅专注于核心`JavaScript`功能，如函数调用、递归、循环和数学运算。然而，SunSpider 也包含针对特定应用的测试，例如通过字符串操作、解压和加密技术，从 JSON 格式输入生成标签云。该测试套件不包含任何用于衡量 DOM 交互性能的测试。

- **Dromaeo `JavaScript`测试套件**：这个`JavaScript`基准测试套件由 Mozilla 开发者创建，旨在允许他们在真实场景中测试自己的`JavaScript`引擎。它包含衡量核心`JavaScript`处理性能的测试，包括二叉树遍历、字符串与数组处理以及素数计算。该测试套件不包含任何 DOM 相关的测试。

- **Dromaeo DOM 测试套件**：除了核心`JavaScript`测试外，Mozilla 团队还创建了一个基准测试套件，用于测试浏览器内的 DOM 遍历与操作。这些测试对 RIA 开发者至关重要，因为许多网页应用通过`JavaScript`实现大量页面交互。DOM 交互速度越快，网页应用的感知性能就越快。遗憾的是，目前该测试套件无法在 IE 6、7、8 版本中正确运行，会在执行过程中触发`JavaScript`异常错误。
