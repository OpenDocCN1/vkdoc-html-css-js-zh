## 引言

富互联网应用程序（`RIA`），或称 `Web` 应用程序，是指那些模糊了 `Web` 浏览器与标准桌面应用程序边界的网站。通过 `Google Gmail`、`Yahoo! Mail` 和 `Microsoft Windows Live Hotmail` 等网站管理电子邮件，与使用 `Microsoft Outlook` 或 `Apple Mail` 等桌面电子邮件客户端一样简单直观。

执行操作时不再需要刷新网页，如果邮件服务器收到新消息，我们期望它能立即出现在收件箱中。

构建以这种方式运行的网站，被视为对传统 `Web` 模式的背离——在传统模式中，提交表单或点击链接以刷新在线论坛查看最新帖子等操作被视为常态。正是这种差异，让一些人将这些 `RIA` 称为 `Web 2.0`，仿佛 `Web` 正在进行一次升级。

从某些方面来看，升级确实在进行，但并非 `Web` 本身的升级。改进实际上发生在我们用来浏览喜爱网站的 `Web` 浏览器上。

在过去几年间，各大主流浏览器逐渐增加了新功能。此外，浏览器制造商之间为了实现一定程度的一致性所做的努力，意味着通过 `JavaScript` 和标准化文档对象模型（`DOM`）脚本的力量，利用从 `Web` 服务器动态加载的数据进行实时页面更新已成为可能。

`Web` 不再是一个静态的地方。

我写这本书的主要目的是帮助你利用 `JavaScript` 的力量，为你的页面添加动态组件，并创建属于你自己的完整 `RIA`。（我假设你已经具备一些 `HTML`、`CSS` 和 `JavaScript` 的知识。）然而，能力越大，责任越大。我强调要确保你理解创建响应式用户体验的重要性——这种体验应能激发访问者的兴趣，而不是让他们感到沮丧。

我还强调，你有能力通过设计发挥创造力，让你的应用程序在外观和行为上都优于任何静态网站。你将看到如何使用自定义构建的用户界面组件，这些组件不会牺牲可用性或可访问性。到本书结束时，你应该有信心构建自己的网站或 `RIA`，并确信它是以健壮、可靠、高效、美观且高度可访问的方式构建的。
