# 创建清单

在你的空清单文件中添加以下属性：`manifest_version`、`name` 和 `version`。这些是清单文件中的必填字段。`manifest_version` 代表清单文件格式的版本。`name` 代表扩展程序的名称。同样地，`version` 是扩展程序的版本。

`manifest_version` 属性接受一个大于 0 的整数值。在撰写本文时，`manifest_version` 属性的有效值是 2，这表示它是清单文件格式的第二个版本。`version` 属性接受一个字符串值，该值由（一至四个）以点分隔的整数（介于 0 和 65536 之间）组成。同样地，`name` 属性接受一个包含扩展程序名称的字符串值。你还可以添加一个 `description` 属性（带有相应的字符串值），它表示扩展程序的纯文本描述。

**注意** Google Chrome 浏览器中的自动更新系统会比较扩展程序的（前述）版本，以确定该扩展程序是否需要更新。如果已发布的扩展程序版本字符串比已安装的版本更新，则扩展程序会自动更新。在编写本书时，扩展程序的更新检查频率是每五小时一次。
