# 创建扩展程序的技术

虽然 Google Chrome 扩展程序为用户提供了丰富的功能，但同时也为开发者创建扩展程序提供了极大的便利。创建 Google Chrome 扩展程序所使用的技术不过是原生的 HTML、CSS、JavaScript 以及（最重要的是）JSON！正因为如此，与为其他浏览器开发扩展程序相比，为 Google Chrome 浏览器开发扩展程序的学习曲线更为平缓。是的，Google Chrome 扩展程序可以在任何桌面操作系统上构建。毕竟，这些扩展程序只是一堆 HTML 和 JavaScript 文件！

## 这些技术是如何使用的？

显而易见，HTML 和 CSS 用于创建扩展程序中的视图。JavaScript 用于提供应用程序逻辑，以及访问 Google Chrome 扩展程序框架提供的 API 和组件（扩展程序组件和 API 的深入介绍分别在第 2 章和第 3 章中提供）。最后，JSON 用于创建扩展程序的清单文件，以便向 Google Chrome 浏览器提供关于自身（该扩展程序）的信息。

### 扩展程序 API

Google Chrome 扩展程序在 Chrome 浏览器中运行于沙盒中。这种沙盒允许扩展程序的代码（即 JavaScript 代码）进行`隔离`执行。

这基本上意味着 Chrome 浏览器中可能安装了数百个扩展程序，但这些扩展程序不会自动感知彼此的存在。这意味着：

- 不同的扩展程序不会意外地相互连接。
- 一个扩展程序不能自动访问属于另一个扩展程序的代码或内存。
- 不会发生任何名称冲突。
- Chrome 浏览器不会混淆你的扩展程序中的 `Script_A.js` 和另一个扩展程序中的 `Script_A.js`。
- 对于属于扩展程序的其他资源（如 HTML、JSON 文件、图像等），情况同样如此。
- 扩展程序可以以确定且受控的方式相互连接（用于通信）。
- 扩展程序框架提供了一套消息传递 API，用于支持一次性连接以及长期连接（更多内容将在第 3 章中介绍）。

> **注意：** 除了此处描述的沙盒机制之外，Chrome 浏览器还提供了另一种沙盒机制（对从扩展程序注入到网页中的脚本进行沙盒化）。你将在第 3 章中了解相关内容。

Chrome 扩展程序在增强 Chrome 网络浏览器的功能方面非常实用。它们能够通过组合 Chrome 浏览器的不同功能来提供通用功能。例如，考虑一个扩展程序，它访问（Chrome 提供的）标签页和闹钟 API，以便在预定义的时间间隔（例如一天）后打开一个标签页。

Google Chrome 扩展程序框架为扩展程序提供了许多专用 API，这些 API 允许访问 Chrome 浏览器的强大功能。这些 API 几乎可以访问 Chrome 浏览器中的所有功能！

> **注意：** 虽然扩展程序框架提供了大量的专用 API，但扩展程序仍然可以使用浏览器提供给网页的所有标准 API（也称为标准 JavaScript API）。这些就是你已熟悉的核心 JavaScript 和文档对象模型（DOM）API。此外，还支持 `XMLHttpRequest`、HTML5（及其他新兴）API、WebKit API（用于 CSS 动画、滤镜等）和 V8 API（如 `JSON`）！

Chrome 浏览器支持的 HTML5 及其他新兴 API 包括音频、画布、地理位置、本地存储、通知和视频。要了解更多关于这些 API 的信息，请访问网址 `https://developer.chrome.com/extensions/api_other`。

使用这些 API，你可以将 Chrome 浏览器提供的不同功能与我们的扩展程序集成。这些功能列表包括用于闹钟、书签、历史记录、标签页、操作、存储、通知、搜索等的 API！你将在第 3 章中学习这些 API。
