## 验证 JSON 文件

现在，在你最喜欢的文本编辑器中打开 `manifest.json` 文件。但在开始之前，有一件重要的事情需要注意：JSON 文件*不能*包含注释。这包括单行注释和多行注释。在 Chrome 网上应用店上传扩展程序包时，大多数错误都是由清单文件中的此类注释引起的。在 Chrome 浏览器本地测试扩展程序时，这些错误不会被报告。

**注意** 不过，为了演示目的，代码清单和相关材料中*使用了*注释。

因此，每当你觉得清单文件状态不佳时（例如，可能包含一些拼写错误或其他格式错误），可以放心地尝试任意*JSON 校验工具*。网上有大量此类在线校验工具。例如，[`jsonlint.com`](http://jsonlint.com/)、[`jsonschemalint.com`](http://jsonschemalint.com/) 等。话虽如此，你现在终于可以打开清单文件进行编辑了。
