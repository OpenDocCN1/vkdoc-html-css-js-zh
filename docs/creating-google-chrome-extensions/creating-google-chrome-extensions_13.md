# 注意
内容脚本（一种注入到访问网页的脚本组件）对 Chrome 扩展程序 API 的访问权限非常有限，因为它们不表示扩展程序运行时。它们只能访问以下 API：`chrome.runtime`、`chrome.extension`和`chrome.storage`。但内容脚本可以访问常规网页脚本可以访问的所有标准 JavaScript API。此外，它们可以与扩展程序运行时交互（使用消息传递 API）。

### 输入组件：第一部分
输入组件是 Google Chrome 扩展程序框架提供的*交互功能*。扩展程序并不严重依赖输入，但它们至关重要，因为它们是进入扩展程序核心逻辑的入口点。例如，考虑一个扩展程序，它从所有打开的标签页的 URL 中搜索单词并返回匹配的 URL。为此，扩展程序至少需要提供一个工具栏按钮（即 Browser-Action 或 Page-Action，如下所述），按下该按钮时会显示一个弹出窗口，其中包含用于输入要搜索单词的文本字段。类似于这种情况，扩展程序还有许多其他方式依赖一个或多个输入组件来触发某些响应（来自脚本组件）或仅显示弹出窗口。
