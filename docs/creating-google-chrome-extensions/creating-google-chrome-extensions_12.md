# 注意
扩展程序本身有许多关联事件。这些事件是`chrome.runtime`（API）对象的属性。以下是与扩展程序相关的一些最有用的事件——`onMessage`、`onConnect`、`onConnectExternal`、`onInstalled`和`onUpdateAvailable`。

### 代表运行时的脚本
在已加载的扩展程序中，能够监听从输入组件触发的事件或扩展程序发生的其他事件的脚本（脚本组件）代表扩展程序运行时。这些脚本包括弹出脚本和事件脚本。但由于弹出脚本仅在弹出窗口打开时执行，您将更多地依赖扩展程序中的事件脚本（这是一个在后台长期运行的脚本）来监听每个事件（从任何输入组件触发，或从扩展程序自身触发，包括扩展程序安装、卸载、更新等时触发的事件）。

不表示扩展程序运行时的脚本是内容脚本。

显然，浏览器中加载的网页永远不能代表扩展程序运行时。但是，正如您将在第 3 章中看到的，网页脚本仍然可以与扩展程序运行时和内容脚本交互（使用消息传递 API）。
