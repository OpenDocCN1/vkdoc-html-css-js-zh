# 第 2 章 ■ 架构概述

清单 2-4 和 2-5 包含了 `HelloShortcutKey` 扩展的代码示例。

该扩展为浏览器动作设置了一个默认图标（`icon-1.png`）。借助 `onCommand` 监听器，它通过调用 `chrome.browserAction.setIcon` 方法将浏览器动作图标更改为 `icon-2.png`。对于此扩展，您可以使用自己的图标或使用第 2 章练习文件文件夹中提供的图标（见图 2-9）。

图 2-9. 练习文件：`HelloShortcutKey`

如清单 2-5 所示，`addListener` 方法用于将监听器附加到 `onCommand` 事件。监听器函数接收一个字符串参数 `command`，该参数表示执行的命令（即快捷键）的名称。在这种情况下，如果 `command` 被记录到控制台，它将显示字符串 `"shortcut-key to change the extension icon"`。当扩展在清单中定义了多个命令时，此参数很有用。要分离监听器内部的逻辑（基于不同的命令），您需要根据执行的命令（名称）进行分支处理（例如，使用 `if` 或 `switch`）。显然，最好避免为命令使用长而描述性的名称，以简化比较。

> **注意** 不要混淆 `addListener` 和 `addEventListener` 方法。后者属于您已经熟悉的 `DOM API`。
