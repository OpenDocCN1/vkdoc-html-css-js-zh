# 致谢

首先，我要衷心感谢 Apress 出色的团队为我提供了撰写本书的绝佳机会。当 Celestin 通过 LinkedIn “发现” 我并询问我是否愿意写一本书时，这听起来像是一项直截了当且轻松的任务。在接下来的一个月里，他耐心地指导我完成了为本书准备初始提案的整个过程，并帮助我最终确定了它。随后，当我开始撰写各章节的实际工作时，Rita 始终陪伴在旁。她就像一位 Scrum 大师，随时提供帮助。即使我的进度落后，她也会温柔地督促我，确保我完成所有必要的工作以赶上进度，并以可交付的增量形式提交章节。谢谢 Celestin 和 Rita 没有放弃我！

我还要感谢 Matt Moodie 以及 Apress 在幕后辛勤工作的大型团队，感谢他们所有的努力。此外，审校者的审阅反馈和关键意见是作者的生命线——这是对一个仍相当粗糙的产品给出的第一份反馈。我衷心感谢洛凯什·耶尔（Lokesh Iyer）的技术审校。

我无法充分感谢我的专业网络多年来丰富我的学习之旅——我的前雇主、客户、经理、同事、团队成员、学生、我博客的读者、讲座的听众，以及其中最崇高的一群人——志愿者伙伴们。感谢你们提供的所有支持和学习机会，并让我每天都成为更好的专业人士。

最后，尽管编辑团队和审校者付出了勤奋的努力，但本书中的所有错误和不足之处，我必须承担责任。欢迎告诉我如何能让本书变得更好。
