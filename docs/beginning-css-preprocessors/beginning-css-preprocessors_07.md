# 简介

CSS 预处理器在几年前开始流行。这个概念让我着迷：允许使用包含变量、函数、混入（mixins）等一或多个特性的预处理器文件。在开发完成后，这些特殊文件会被编译成所有 Web 浏览器都能理解的常规 CSS 文件。

# 排版后的内容

“如果没坏，就别修”，秉持着这一信条，我曾一度避免使用 CSS 预处理器。我最初的想法是：“为什么要在我的工作流中增加不必要的流程呢？”此外，我也担心陡峭的学习曲线，而命令行界面则给了我另一个拒绝 CSS 预处理器的理由。

最终，在观看了一些播客并阅读了大量文章后，我豁然开朗。这让我意识到：“哇，我应该把这项技术融入我的工作流中！”

从那时起，我就在项目中开始使用 `Sass` 和 `Less`，它们似乎让我的开发工作变得简单高效得多。通过本书，你将了解这两种预处理器是如何工作的。

你将首先学习预处理器的概念及其工作原理。你还会了解市面上几种流行的预处理器。接着，我们将探讨一些基于图形用户界面的工具，这些工具适用于不熟悉命令行界面的用户。

随着章节的深入，你将全面了解这两种预处理器——`Sass` 和 `Less`，并学习一个基于 `Sass` 的流行框架 `Compass`。

本书分享的知识将帮助你提高生产力，编写出可维护且可扩展的 CSS 代码。
