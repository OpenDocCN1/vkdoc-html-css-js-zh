# 这些应用程序的“观感”相当简陋，这应该能激励你去改进它们！

使用图片来作为原始目标和命中目标虽然有趣，但你必须记住在上传项目时包含这些文件，并确保文件名和扩展名正确无误。我曾遇到过一个系统，它会自动将`JPG`文件重命名为`JPEG`，这需要纠正。你可以选择自己的目标。也许你对小鸡情有独钟！

你需要测试程序在三种情况下是否正确运行：当球落在目标左侧时、当球击中目标时、以及当球越过目标时。请注意，我调整了数值，使得小鸡必须被击中身体中部，因此球碰到头部或尾部不会触发羽毛特效。

你可以通过更改变量（例如`startRockx`）来调整大炮及其目标、命中目标的位置，以及弹弓、小鸡和羽毛的位置，还可以修改重力变量。如果你将弹弓放得离目标更近，就会有更多方式击中小鸡：向左拉得更远进行直线射击，或者向下拉进行高抛射击。祝玩得愉快！

## 第 4 章 炮弹与弹弓

正如我所说，你可以在炮弹和弹弓应用中使用动画 GIF 作为命中目标，这样可以产生很好的视觉效果。

如果你确实使用了更多和/或更大的图片或其他媒体，那么最好采用一种技术，确保所有媒体在用户使用前已从你的网站下载完毕。我将在第[6](http://dx.doi.org/10.1007/978-1-4842-4155-4_6)章中介绍这种技术，当玩家成功完成一轮时，它会播放视频片段和音频片段。

### 总结

在本章中，你学习了如何创建两个弹道应用。理解它们的相同点和不同点非常重要。所涉及的编程技术和 HTML5 特性包括：

-   程序员自定义对象
-   使用`setInterval`为动画设置定时事件，与弹跳球的实现方式相同
-   使用`push`方法构建数组，并将该数组作为待显示内容的列表
-   使用`splice`方法修改数组
-   使用三角函数和变换来旋转大炮，并解析大炮和弹弓应用中的水平与垂直速度，以模拟重力
-   使用表单进行玩家输入
-   通过`addEventListener`处理鼠标事件（`mousedown`、`mousemove`和`mouseup`）以获取玩家输入
-   在画布上绘制弧线、矩形、线条和图像

程序员自定义对象以及使用对象数组进行显示的技术将在后续章节中再次出现。下一章将聚焦于一款名为“记忆”或“配对”的经典游戏。它使用了不同的定时事件，以及在第[1](http://dx.doi.org/10.1007/978-1-4842-4155-4_1)章中介绍过的`Date`函数。

### 引言

本章演示了一款卡牌游戏的两种版本，这款游戏有多种叫法，如*记忆*游戏或*配对*游戏。卡牌牌面朝下放置，玩家每次翻开两张（通过点击），尝试找到匹配的对子。程序会将匹配的牌从牌桌上移除，并将不匹配的牌（虚拟地）翻回。当玩家匹配完所有牌对时，游戏会显示所用的时间。

我描述的第一个游戏版本使用多边形来表示牌面，第二个版本则使用家庭照片。你会注意到其他差异，这些差异是为了说明 HTML5 的多种特性而设计的，但我也强烈建议你思考这两个版本的共同点。
