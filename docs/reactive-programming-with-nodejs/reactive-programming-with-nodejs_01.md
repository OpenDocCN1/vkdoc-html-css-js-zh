## 引言

响应式编程无疑是当下的趋势，许多前端开发者开始重视它，因为他们工作的性质（基于事件的 JavaScript）与之非常契合。网络上针对前端环境的相关文章很多，但遗憾的是，后端领域却没有得到同等的关注。

得益于 Node.js，我们现在在服务器端拥有了一个非常相似的环境，这使得开发者能够以前端开发者在日常工作中使用该技术时的相同方式，来思考响应式编程（甚至函数式响应式编程）。

本书对 Node.js 开发者（甚至是其他后端开发者）来说会很有趣，因为它将为他们提供一种新的、不同的方法来解决日常遇到的问题。

那么，请坐好，放松心情，享受这本书吧！
