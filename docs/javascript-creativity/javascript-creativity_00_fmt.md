## 前言

万维网似乎总是在追赶。早在 90 年代，网络与 CD-ROM 竞争时处于劣势——至少在技术实现方面是如此。CD-ROM 提供了更丰富的交互性、更好的视觉效果和使用音频的可能性。但从长远来看，这并不重要。CD-ROM 根本无法与万维网的浩瀚无垠相抗衡。

后来，Macromedia（以及后来的 Adobe）Flash 与网络展开了较量。在动画、音频和视频方面，网络似乎再次无法与其竞争对手匹敌。然而，网络又一次比其更华丽的对手更持久。

最近，我们在移动领域看到了同样故事的重演。与原生应用相比，网络似乎无法提供同样丰富的交互体验。但即使在这里，我怀疑在原生应用的热潮消退很久之后，网络仍将比以往任何时候都更强大。

这些专有技术——CD-ROM、Flash、原生应用——每一项都可能被解读为对开放网络的威胁，但我更愿意将它们视为网络的研究与开发部门。总会有某种竞争技术在表面上看起来旨在挑战网络的主导地位。实际上，这些技术展示了 web 开发者希望从浏览器和标准化机构那里获得什么样的功能。如果没有 Flash，我们会有 CSS 动画吗？如果没有原生应用，人们会投入那么多精力来提供对设备 API 的访问吗？

网络总会落后于其他技术，这没关系。随着时间的推移，网络的功能集不断增长，同时始终保持向后兼容性（这是那些竞争技术所严重缺乏的）。网络功能集的增长有时看起来可能慢得令人痛苦，但值得偶尔退后一步，看看我们已经走了多远。

这本书就像一张快照，捕捉了当今网络浏览器所能实现的尖端功能。我们取得的进步可能会让你感到惊讶。它当然让我感到惊讶。我对我们现在能用音频、视频和动画实现的成就感到相当震惊。而最擅长让人震惊的人莫过于 Shane 了。他就像网络开发界的 Doogie Howser。（问问你的父母。）

那么，准备好开始一段狂野之旅吧。Shane Hudson 将带你走向前沿。

Jeremy Keith
网络大使

## 致谢

直到我写了这本书，我才真正理解为什么每一位作者的致谢都会说：“如果没有……这本书就不可能完成。”如果不是那些在写作过程中帮助过我的人，我早就放弃了，这本书也就不会存在了。

首先，我必须感谢我出色的编辑路易丝·科里根，感谢她所做的一切。起初我只是随意问她，出书应该找谁谈，结果仅仅几个月后，我就签下了合同。在整个过程中，她一直鼓励我（有好多次我都想干脆放弃写作），并帮助我构思每一章的内容。没有路易丝，我确信这本书只会是我脑海中的幻想，但如今你们却能将它捧在手中。谢谢你，路易丝，感谢你对我的信任。

在开始写这本书之前，我完全不知道协调编辑这个角色意味着什么。马克·鲍尔斯和克里斯汀·里基茨是我的两位协调编辑，他们都是非常了不起的人。我完成这本书所花的时间远比预想的要长，但马克和克里斯汀都做得非常出色，确保了整个过程尽可能顺利地进行。

Apress 出版社最后一位我要衷心感谢的员工是琳达·塞弗特，她负责了整本书的文字编辑。虽然我现在写了一本书，但我本质上还是个程序员，所以琳达就像一位魔术师，把我那些零散的词句变成了值得出版的句子。

我知道还有许多其他在幕后为这本书工作的人，我很少与他们直接联系。在此，我也要向这些人表示感谢。

我这本书的技术审校者是基思·柯克，我真的幸运至极。基思是一个很棒的人，也是一位杰出的程序员。他不断地给我提出改进建议，不仅涉及代码，还包括章节的流畅度。许多代码都是在深夜写成的，他能发现很多改进代码的方法，而不仅仅是测试代码是否能无错运行。

除了与我一同参与本书工作的人之外，还有一些其他人因在本书创作过程中给予的各种支持而值得感谢。首先是来自澳大利亚的程序员瑞安·拉姆沃伊。我从未见过瑞安本人，但他是我在网络上认识的第一位程序员，并且从那以后一直支持着我。正是瑞安对用计算机编程创作音乐的兴趣，让我学到了我在第五章中关于 JavaScript 音乐理论的大部分内容。在本书的开头部分，瑞安也对示例项目的构思提供了很大帮助。

我当然还需要感谢杰里米·基思为本书撰写序言。我真的很希望杰里米能写，但没想到他竟然答应了！他是一位出色的作家，思想深刻，是网络上真正宝贵的人才。当我问他希望在名字旁边加上什么头衔时，我原以为会是与 Clearleft（他是创始人之一）相关的头衔。没想到他却要求写“网络大使”。如果是别人，我会对这个头衔有所警惕——但杰里米确实配得上。

斯图尔特·梅莫也是第五章的灵感来源，他发表了一场精彩的演讲，题为“JavaScript 是新的朋克摇滚”，我强烈推荐你们去看一看。斯图尔特还用 Web Audio API 做了许多其他有趣的事情，所以去看看他的网站：[`www.stuartmemo.com`](http://www.stuartmemo.com/)。最初，我打算自己编写一个 3D 音乐可视化程序，但无论我怎么做，都无法（至少在有限的时间里）做得比史蒂文·维滕斯已经详细解释过的效果更好。因此，我非常感谢史蒂文允许我在本书中使用他的可视化程序。我强烈推荐你们阅读他网站上那篇解释可视化背后数学原理的文章，以及史蒂文那个令人惊叹的网站上的其他文章：[`www.acko.net`](http://www.acko.net/)。

马特·戴蒙德和基思·诺曼对本书的贡献也非常大。马特编写了 `Recorder.js` 脚本，用于录制 Web Audio API 节点，并在我在使用它遇到问题时提供了帮助。基思·诺曼为我在第八章中使用的 Web RTC 代码编写了基础代码，并帮助我审阅了代码。

在整个写作过程中，我得到了家人和朋友的大力支持，尤其是我的父母（这本书正是献给他们）。每个人都为我感到兴奋，并努力让我保持热情。我要特别感谢肯特大学计算学院和普利茅斯海洋实验室遥感系的全体成员，感谢他们持续的支持。我还要感谢我的室友埃德·格里尔和西尔瓦娜·马洛尔·霍亚，他们忍受了我没日没夜地工作，并帮助我完成了这本书。还有很多其他人我也希望能一一感谢，但最后要感谢的是我的朋友萨姆·哈钦斯，我认为他是一位语言大师。他帮助我润色了一些措辞，并且是另一个帮助我保持热情的人，没有他，我可能无法完成这本书。最后，感谢 Twitter 上所有在我写作过程中忍受我不断发牢骚的人！
