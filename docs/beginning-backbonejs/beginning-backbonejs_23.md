# 总结

本章列出了在构建专业 Backbone 应用时需要牢记的一些最重要的实践。内存管理是大多数应用开发者关注的核心问题之一，而性能、响应速度以及常规代码管理同样占据重要地位。由于 Backbone 的非固执己见特性，开发者在构建应用时拥有很大的自由度。牢记本章中的实践，你将能够引导你的团队避开一些 Backbone 开发者常见的陷阱。

考虑到以上所有因素，利用第 7 章中列出的插件，或采用第 10 章中讨论的 Marionette 或 Thorax 库，是非常明智的选择，这主要是因为 Backbone 应用中的大多数错误都源于对视图的不当管理。

感谢 Phillip Whisenhunt、Addy Osmani、Derick Bailey、Ian Storm Taylor、Rico Sta Cruz 和 Oz Katz 提供的富有洞察力的文章，它们突显了本章中使用的许多最佳实践、技巧和模式。
