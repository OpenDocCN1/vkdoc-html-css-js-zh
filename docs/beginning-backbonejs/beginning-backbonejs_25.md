# 总结

本章探讨了确保应用程序保持模块化和可测试性的一些最佳实践。我们了解了如何利用 `RequireJS` 将代码拆分为带有真实依赖管理的简单模块。`RequireJS` 不仅能让代码更易于维护和测试，还能创建一种结构，使新加入团队的开发者能够更轻松地理解和浏览代码。除了演示如何将 `RequireJS` 集成到现有的 `Backbone` 应用中，本章还介绍了 `Yeoman`，它作为一种工具，可以从零开始创建新的 `Backbone` 项目，无需编写大量样板代码，同时依然能享受到 `RequireJS` 带来的好处。

最后，我们探讨了如何利用两种经典的设计模式——**外观模式**和**中介者模式**——来让代码更易于管理。需要牢记的关键点是：尽管 JavaScript 是一种动态语言，几乎允许你为所欲为，但始终有机会为代码应用真正的结构，使其经得起未来考验，并随时准备应对项目生命周期后期新增的任何应用程序需求。
