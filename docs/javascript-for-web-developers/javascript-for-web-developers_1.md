# 引言

给性急的读者：

如果你急于开始，可以忽略这一切，直接跳到“设置”部分。这部分非常重要，能让后续内容更容易上手。

当你加载一个网页时，你很可能会看到多达五种技术共同作用的结果。其中两种发生在网络服务器端，三种发生在浏览器内部。

在服务器端，页面及其组件很可能由软件生成。通常（但不一定），该软件可能是像`PHP`这样的脚本语言。进而，该软件可能使用名为`SQL`的数据库语言访问数据库以获取部分数据。

最终输出将以`HTML`的形式呈现。这段`HTML`会被发送回浏览器。

随后，浏览器会开始处理这段`HTML`。如果引用了额外的图片，浏览器会请求这些图片，并在它们到达后使用。`HTML`很可能还包含对`CSS`和`JavaScript`文件的引用。涉及的三种重要浏览器技术如下：

*   **`HTML`**：定义页面内容的语言。浏览器本身会为其赋予基本外观，但该外观很可能由`CSS`加以增强。
*   **`CSS`**：定义页面呈现的语言。这包括颜色、文本属性、布局以及一些视觉效果。`CSS`多年来发展迅猛，已变得非常复杂，甚至包含一些简单的动画。
*   **`JavaScript`**：定义页面行为的语言。大多数非静态内容都由`JavaScript`控制。`HTML`确实包含一些与用户的交互，例如网络表单，但`JavaScript`能让整个页面实现交互。

本书的主题自然是`JavaScript`。

最好在电脑前阅读本书，这样你可以亲手实践所有概念。随着阅读的深入，你将很好地理解`JavaScript`的功能以及如何实现这些功能。

首先，第 1 章将带你了解`JavaScript`的一些基本概念，并展示如何使用浏览器内置的开发工具进行实验。第 2 章将通过一个简单游戏，应用这些概念及一些新知识。

使用`JavaScript`的一个重要部分是与网页本身交互，第 3 章将带你了解相关理念，随后第 4 章将构建一个幻灯片项目，将这些理念付诸实践。

许多网站包含供用户使用的表单。第 5 章将展示如何处理网络表单，第 6 章将使用`JavaScript`和表单构建一个专用的简易计算器。

第 7 章将重点介绍`JavaScript`如何与`CSS`协同工作，并探讨事件监听器——这是`JavaScript`与用户操作之间的基本接口。随后，我们将在第 8 章和第 9 章中运用这些知识来显示和隐藏内容，并生成一个弹窗图片画廊。

最后，在第 10 章中，我们将了解 Ajax，它让`JavaScript`能够与网络服务器通信，以获取额外资源。

接下来会发生什么，当然取决于你。通过本书的学习，你将能够创建自己的交互式网页，并对你可能继承的任何网页项目进行改造。

## 一点历史

早期的万维网非常静态，如果一切不是那么新颖，这可能会令人感到无聊。所谓“静态”，是指一旦加载页面，剩下的只是浏览它，并点击链接加载下一个页面。

1995 年，当时开发了最重要图形化网页浏览器的网景公司，决定通过在浏览器中添加一种脚本语言来活跃气氛。这将使页面更具交互性，并能动态改变页面内容。

网景公司曾考虑嵌入当时开始流行的较新语言和平台——Java，但最终决定在布兰登·艾克的指导下创建自己的语言。即便如此，Java 也以插件和“小程序”的形式流行起来，至今仍在一些其他环境中使用。

这种浏览器脚本语言本应基于另一种名为 Scheme 的语言，并命名为 LiveScript。然而，由于当时 Java 的流行，其语法被设计成类似 Java，语言也被重新命名为`JavaScript`，这从此成为混淆的源头。`JavaScript`和 Java 根本就不是同一种语言，尽管在名称和语法上存在表层相似性。

微软不甘落后，在其名为 Internet Explorer¹的新浏览器中，添加了`JavaScript`的一个克隆版本，称为`JScript`。然而，两者始终不完全相同。随着浏览器的发展，它们之间的差异也越来越大。1996 年，网景公司将`JavaScript`提交给`ECMA`进行标准化。

微软后来主导了网络，同时抵制标准化的努力。2004 年，网景的“转世”公司 Mozilla 发布了 Firefox，开始松动微软对网络的垄断，推动`JavaScript`标准化的力度也随之加强。谷歌于 2008 年发布了 Chrome，如今`JavaScript`的力量日益强大。

最初只是`JavaScript`的语言，如今被称为`ECMAScript`，它现在是一种可以在网络浏览器之外的环境中使用的语言。在网页浏览器中使用时，它仍被称为`JavaScript`。

`ECMAScript`及其衍生的`JavaScript`，多年来经历了一些重大的语言改进。如今，它已是一种成熟的语言，拥有许多复杂的编程特性。



## 本书结构

你将学到的每一段 JavaScript 都很有用，而你所看到的每个示例都仅仅是示例。有些示例比其他示例更贴近实际。

本书主要包含两类章节：

*   有些章节专注于学习一系列新技能。鼓励你坐在电脑前边学边实践。
*   有些章节则用于完成项目。其中会通过少量实验来解释一些要点，但主要目标是编写出能实现有用功能的连贯脚本。

在某些情况下，你会编写一些代码，这些代码可以保存在代码库中，以便在其他项目中复用。

## 旧有方法

JavaScript 的工作方式已经有了许多改进，尤其是在最近几年。然而，每个浏览器厂商都会按照自己的节奏实现这些改进，每个用户也会按自己的时间安排更新浏览器。因此，为 Web 编写 JavaScript 需要在使用尽可能现代的技术与不抛弃太多用户之间取得平衡。

值得庆幸的是，现代浏览器已经超越了多年来令 Web 开发者头疼的那些重大差异。它们或多或少都与最新的主流 Web 技术兼容，并且大多朝着可接受的标准迈进。

在本书中，所有 JavaScript 代码都将在所有主流浏览器上运行，即使这些浏览器版本稍旧。如果你想检查某个特定功能，可以查阅以下网站：

*   Can I Use：`https://caniuse.com/`
*   MDN Web 文档：`https://developer.mozilla.org/zh-CN/`

本书中偶尔会提及一些旧有的实现方式。这并非因为你需要它们，也不是为了唤起怀旧感，而是因为你很可能会在其他代码中遇到这些技术，比如你正在维护的代码，或者在网络上偶然发现的代码示例。

## 你应该已掌握的知识

Web 开发是关于网页的，而 JavaScript 是其中的一部分。要真正理解发生了什么，你还应该对网页有所了解。

当然，我们假设你已经在 Web 上花过一些时间，并且知道如何使用表单和点击链接。

从技术角度来看，你还应该了解 `HTML`。你不必成为专家，在涉及具体应用时，我们会在书中介绍一些细节。但你应该对 `HTML` 的工作原理有一些基本了解。

大部分视觉工作是由 `CSS` 完成的。这是网页的样式表语言，你也需要对其有所了解。同样，你不必成为专家，但最好知道它是什么以及如何使用。任何复杂的内容都会在具体应用中加以介绍。

如果你在其他语言（如 `C++`、`Python`、`PHP`、`Java` 或数十种其他语言）方面有任何编程知识，那么你已经具备了一些理论基础。

但请记住，每种编程语言都是不同的，所以不要期望新语言与其他语言完全一样，否则你可能会措手不及。抱着“这门语言*应该*与其他语言一样”的态度是个错误。
