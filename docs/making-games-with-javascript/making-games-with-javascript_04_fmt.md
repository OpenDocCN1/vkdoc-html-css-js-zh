我是个游戏迷。早在成为程序员之前，我就已经是游戏玩家了。然而，直到现在我才尝试构建一款游戏……就在几周前，一位同事草绘了一款简约而精美的平台游戏。当我看到它的那一刻，我就知道我想把它做出来。

知道从何入手总是很难。许多关于游戏制作的书籍和教程通常是用 Java、C++ 或其他你还没学会的语言编写的。因此，当你还需要学习新语言时，制作游戏的复杂性就增加了。

相反，我将使用现代 JavaScript 来为网页浏览器制作游戏。它们使用起来毫不费力，并且能在任何地方运行。如果你曾想过制作一款游戏，那就加入我吧。我们将从零开始，很快就能构建出有趣的游戏。
