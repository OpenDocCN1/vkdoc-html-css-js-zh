# 17. 更多项目构想

你可能出于专业需求需要创建数字出版物，但使用 `InDesign` 的工具来创建各种文档（你可以与同事、朋友、家人和合作伙伴发布和分享）会更有趣。你越多地使用本书中介绍的方法，你就会开发出越多的应用程序来创建文档，不仅限于专业用途，也可用于休闲娱乐。

## 17.1 撰写你的自传

许多人常说，“你应该写本书。”人们常常认为自己的过往经历非常有趣，以至于应该将这些事件记录在出版物中。如果你曾想过写这样一本书，那么现在就是时候了。

你可以创建一个可重排的 `EPUB`，并添加照片、音频和视频来编写一个有趣的故事。这可能不会被出版社看中，进而改编成汤姆·汉克斯或詹妮弗·劳伦斯主演的电影，但你很可能会从认识你的人那里得到很多赞誉。

从一个个人故事开始你的写作生涯，并与朋友和家人分享。

## 17.2 创作一本儿童读物

构思一个可能让你的孩子或家人感兴趣的故事，并规划一本交互式图书。儿童读物有很多图片，当你添加动画和音频时，孩子们会在平板电脑上玩上一整天（见图 17-1）。

![A432409_1_En_17_Fig1_HTML.jpg](img/A432409_1_En_17_Fig1_HTML.jpg)

图 17-1. 一本儿童读物的封面

不必担心自己不是一位伟大的艺术家。有些卡通人物看起来根本就不像 DC 漫画的绘图。你可以先从搜索互联网上的人物和动物角色画开始。下载一些图像文件，并将它们用作 `Adobe Illustrator` 等绘图程序中的模板。如果不用于公开发行，则无需担心版权问题。修改这些图画，使其与你下载的图像略有不同，这样就没什么问题了。

将图像文件导入 `InDesign`。至于文本，可以参考一些儿童读物，了解特定年龄段的孩子在每页上应该有多少文本。对于年幼的孩子，一行文本就足够了。

使用运动路径为对象添加动画效果，并引入声音。你可以从互联网上的许多网站下载免版税的声音。最重要的是构思一个孩子们感兴趣的故事，或许还能传递一些信息。

完成设计后，创建一个固定版式的 `EPUB` 并将其加载到平板电脑上。这可能需要一些功夫，但孩子们会享受它一段时间。不过要注意，他们可能会要求你写更多的书。

## 17.3 创建一本 EPUB 食谱

这是整理你一些最喜爱食谱的好方法。包括传统的配料表、准备时间和烹饪时间，你还可以添加视频。当你在厨房准备一些最喜爱的菜肴时，拍摄视频。在 `Adobe Media Encoder` 中优化视频，并将它们放入 `InDesign` 文档中。

这个项目可以随着时间的推移持续开发。将你的文件放在手边，当你拍摄了新视频时，将其连同文本和照片一起添加到文档中。当你准备发布时，将文件导出为固定版式的 `EPUB`。对于喜欢你的美食的朋友来说，这可能会是一份不错的圣诞礼物。

## 17.4 制作一张圣诞贺卡

说到圣诞节（或任何其他场合），你可能想考虑制作一张贺卡。你可以在卡片中添加视频、照片和音频，并与你圣诞名单上的所有人分享这张卡片。

使用 `Adobe Publish Online` 发布文档。向你名单上的人发送一封包含 `URL` 的电子邮件，这样他们就可以查看你的贺卡了。

## 17.5 分享活动邀请函

你可能有一个社交聚会、公司野餐、派对、婚礼、周年纪念或其他特殊场合的邀请函，你想邀请精选的朋友和家人前来。当你添加动画时，这份邀请函会得到很多关注。

创建一个 `Adobe Publish Online` 文档，并与你想邀请参加活动的人分享 `URL`。

## 17.6 在 Facebook 上发布活动

如果你不需要限制特定活动的受众——比如体育赛事、足球比赛、当地小学的儿童剧、政治集会或其他此类活动——你可能想让很多人知道这个消息。

创建一个带有一些特色的动画文档。让它变得有趣，这样人们就会想看它好几次。

使用 `Adobe Publish Online` 发布文档，并在你的 Facebook 时间线上分享该文件。定期查看你的 Facebook 账户，看看你获得了多少个赞。

## 17.7 创建动态商业图表

如果你在一家公司工作、担任董事会成员，或者想为需要创意商业图表的朋友提供帮助，可以使用 `InDesign` 中的动画功能，精心设计一个能清晰展示图表信息的方案。

你可以创建动态的柱状图、爆炸式饼图、动画折线图，以及任何你认为合适的图表呈现方式。

将动画复制到新文档中，并导出为 SWF（播放器）文件。将 SWF 文件导入 `InDesign` 文档，然后导出为交互式 PDF。你可以在笔记本电脑上展示该图表，或将 PDF 发送给其他用户。

## 17.8 在文档中使用 QuickTime VR 影片

要创建 QuickTime VR 影片文件，你需要一款能将照片拼接在一起以最终生成影片文件的程序。可以使用像 `Pano2VR` 这样的程序，你可以从 [`http://ggnome.com/pano2vr`](http://ggnome.com/pano2vr) 下载。你可以使用该程序的演示模式进行试用，无需购买。在演示模式下，生成的文件会显示水印。如果你购买了该程序，水印就会消失。

以 360° 视角拍摄多张照片，然后在 `Pano2VR` 中将它们拼接起来。你可以在想要出售的房屋内部拍照。生成影片文件后，将其置入 `InDesign` 并导出为交互式 PDF。

你可以通过点击并拖动鼠标来滚动浏览影片文件的 360° 视图。

## 17.9 在 Photoshop 中拼接全景文件

拍摄多张全景场景的照片。使用三脚架，并让每张照片重叠约 25%。将相机以竖拍模式放置在三脚架上，拍摄一系列照片。

在 `Adobe Photoshop` 的 `Camera Raw` 对话框中打开所有照片。选择屏幕最左侧胶片中的所有照片，然后从下拉菜单中选择 `合并到全景图`，或按 `Ctrl/⌘+M`。在 `Photoshop` 中打开合并后的照片，根据需要进行裁剪和降采样。

将全景图像置入 `InDesign`，然后在 `选项` 菜单的 `固定布局导出选项常规` 窗格中选择 `将跨页转换为横向`。

## 17.10 通过 Dropbox 共享多个 URL

如果你有几个使用 `Adobe Publish Online` 创建的文档，你可能希望轻松访问它们，并定期向他人提供文件链接。为了追踪这些文件和 `URL`，请创建一个包含每个 `URL` 的纯文本文档。

将该文档放入 Dropbox 的 `Public` 文件夹中，用户可以请求获取 `URL` 地址，或者你可以指导用户下载文件。当他们用文本编辑器打开该文档时，只需点击某个 `URL` 即可访问相应文件。这适用于固定布局、PDF 或 `Adobe Publish Online` 文档。对于固定布局和 Adobe PDF 文件，你需要将它们上传到 Dropbox 的 `public` 文件夹。

## 17.11 总结

如果你是 `InDesign` 和/或创建交互式文档的新手，希望本书能帮助你入门。你练习得越多，就越能熟练掌握 `Adobe InDesign`。
