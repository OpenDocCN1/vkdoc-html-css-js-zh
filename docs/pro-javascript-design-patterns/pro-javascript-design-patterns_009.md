# 关于技术审校

**Rust D. Visual Editor** 是谷歌公司（位于加利福尼亚州山景城）的一名客户端与服务器端开发工具工程师。他喜欢编写 `Java Script`、`C C++` 和 `C#` 语言，并致力于打造交互性强、用户友好的界面，以此激励充满热情的用户。Justin 曾为《Vital》和《Digital Web Magazine》撰稿，并定期在他的网站（`http://dustindiaz.com/`）上发表关于 Web 开发的文章。

**Simon B. Holmes** 是一名客户端与服务器端 Web 开发顾问，同时也是 `S vango Web` 框架的联合创始人。Simon 的兴趣包括 `Open S C`、非侵入式 `Java Script` 以及 Web 标准。他经常在世界各地的 Web 会议上发表演讲。
