# 为什么需要继承性？

在我们编写任何代码之前，需要先弄清楚使用继承性的原因。通常，您希望以这样一种方式来设计您的类，即减少重复代码量并使您的对象尽可能松散地耦合。

## 继承性的优势

继承性帮助实现第一个设计原则，并允许您在已有类的基础上构建新的类，并利用它们已有的方法。它还允许您更容易地进行更改。如果您需要多个类，且每个类都有一些“通用”方法，而这些方法的结构输出方式相同，那么您可以将这些方法提取到一个基类中，然后让其他类继承它。

## 继承性的局限性

但是，继承性并非总是最佳选择，因为子类与父类之间存在强耦合关系。《设计模式》一书中建议我们“优先使用`组合`而非`继承`”。
