# Lambda 表达式：像函数一样编程

`addEventListener`函数是注册事件处理函数的基础。在`addEventListener(event, listener)`中，`listener`参数可以是一个函数名，也可以是一个匿名函数。您还可以使用`Event`对象来访问事件相关的数据和功能。

Lambda 表达式（也称作闭包或匿名函数）提供了一种简洁的方式来定义简单的函数，而无需编写完整的`function`关键字、名称和`return`语句。它们通常用于回调函数、事件处理和数组操作。

Lambda 表达式是让你的代码更简洁、更易维护的强大工具。它们通常被用来实现函数式编程风格，例如将行为作为参数传递给其他函数。
