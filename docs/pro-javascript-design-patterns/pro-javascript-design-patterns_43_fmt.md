# 概述

用户界面（UI）由可视元素（如图标、按钮、文本）和用户与设备交互的机制（如触摸、点击、拖拽）组成。

用户界面是应用程序的一个子集。同时，用户界面也允许用户访问应用程序的功能和对象。

用户界面的常见形式包括命令行界面（CLI）和图形用户界面（GUI）。

UI 元素是构成应用视觉语言的基础。它们可以包含图标、颜色、排版和间距等设计属性。

UI 元素通常遵循设计规范中的特定结构，例如输入框、按钮和标签。

在界面中，UI 元素是容器，允许开发者将文本、图像和输入控件组织到可重复使用的模块中。这有助于保持代码库的组织性，并提高开发效率。

UI 元素的灵活性使得它们可以被应用于不同上下文中，从而创造出一致的用户体验。它们通常包含状态管理，例如`hover`、`active`、`focus`等。

UI 组件库是预先构建的、可复用的 UI 元素集合。它们遵循一套设计语言，例如 Material Design，以确保产品中的视觉一致性。

一个精心设计的 UI 能够简化复杂任务，提高用户效率，并增强用户对产品的整体满意度。

如今，大多数 Web 应用依赖诸如`addEventListener(type, listener)`、`querySelector(selectors)`或`createElement(tagName)`等 DOM API，来动态更改页面内容。开发人员还可以使用`Event.preventDefault()`来阻止浏览器的默认行为。

用户界面设计旨在通过运用一致的布局、颜色和排版，使应用易于导航和使用。它通过提供清晰的视觉层次和反馈，帮助用户理解如何与产品互动。
