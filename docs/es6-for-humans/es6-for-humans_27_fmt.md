# 总结

本章我们探讨了在编写本书时已发布的 `JavaScript` 各种微小增量变更以及基于 `ES6` 的更新。`TC39` 的目标是每年发布一次新规范，这些规范从提案阶段进入最终规范阶段，然后被纳入到语言中。它们应当是小型功能更新，不像 `ES6`（`ES2015`）那样是巨大的变革。
