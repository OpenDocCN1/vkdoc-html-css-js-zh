# 引言

如果你有制作视频游戏的愿望，但没有任何编程或游戏开发经验，那么这本书就是为你准备的。Unity 是一个强大的游戏开发生态系统，可用于创建 2D 和 3D 游戏。凭借其基础但功能强大的免费版本，Unity 已经扫清了学习游戏开发的障碍。虽然 Unity 编辑器本质上是可视化和直观的，但你仍需学习编写脚本才能完成游戏。别担心——你只需要一台电脑、一个互联网连接和动力。本书是为游戏开发和编程的完全初学者而写的。

术语“脚本编写”、“编程”和“编码”是同义词，都指编写计算机代码以指导游戏某些行为的过程。虽然这看起来可能有点令人生畏，但正如任何其他努力一样，你只需从起点开始，一次学习一件事。不编写一些代码就无法制作游戏，但创建代码只是游戏开发过程的一部分。在学习寻找和使用角色、动画、特效和其他资源时，你会和编写代码来指导它们在游戏中交互时一样感到乐趣。

Unity3D 的制造商 Unity Technologies 提供了出色的支持文档，这些文档通常包含有效的示例代码。当我还是初学者开发者时，无论是开发移动应用还是视频游戏，我发现几乎所有文档都晦涩难懂，就像是用象形文字写的一样——几乎无法理解。我陷入了一个困境，我需要文档来教我如何使用这些文档！

本书的目的是弥合这个初期的鸿沟——在使用 Unity 制作一个简单游戏的背景下，为你打下编程的基础，同时将你所学的内容与文档中的相关信息联系起来，甚至教你如何使用一些示例代码。本书旨在成为一个跳板：当你完成书中的示例后，你应该能够自信地利用本书中介绍给你的众多资源，在自己的新知识和技能基础上继续构建。

基于此，请按顺序阅读各章节。在前几章介绍了编程概念和 Unity 编辑器的基础知识之后，后续的项目将从一章到下一章逐步构建。为了最大限度地利用本书，请从头开始逐步完成这些项目。学习并（同样重要的）记住所学内容的最佳方法就是亲自动手。此外，这样做也很有趣，并且自己动手完成无疑会更有成就感。

游戏开发行业日新月异，超过一半的游戏开发者（从个人到大型工作室）都在使用 Unity，因此可以肯定 Unity Technologies 正在不断突破界限，以提供更好的工具和游戏引擎性能。特别是在本书编写期间，发生了几项重大变化，影响了动画、粒子系统以及用于快速原型的更好资源。任何来自 Unity 或其他方面影响本书说明的更改，都将在本书 Apress 网页的勘误表部分注明，[`www.apress.com/9781430265863`](http://www.apress.com/9781430265863)。

有时，拥有一个已完成的项目作为参考会很有帮助。你可以在本书 Apress 网页的“源代码/下载”选项卡下找到本书示例的源代码和完成的项目。

学习制作游戏的最佳方法就是动手制作游戏，所以请翻页开始吧！
