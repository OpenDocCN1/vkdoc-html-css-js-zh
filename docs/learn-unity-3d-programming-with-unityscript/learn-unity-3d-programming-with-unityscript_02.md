# 关于技术审校

![A978-1-4302-6587-0_BookFrontmatter_Fig1_HTML.jpg](img/A978-1-4302-6587-0_BookFrontmatter_Fig1_HTML.jpg) 格雷厄姆·麦卡利斯特在 15 岁时首次涉足游戏行业，当时他在 Amiga 电脑上使用 Deluxe Paint 为 16 位游戏绘制加载画面。

他最初在大学学习电子工程；然而，这段经历只持续了两周，因为他意识到自己完全不是从硬件的角度思考问题。转学到软件工程专业后，他立刻如鱼得水，并继续攻读了计算机图形学博士学位。

在电信行业短暂担任软件工程师后，他重返学术界，在贝尔法斯特女王大学担任音乐技术讲师。2006 年初，他借调到哥本哈根一家当时名不见经传的公司，该公司正在开发一款激动人心的全新游戏引擎。这款引擎叫做 Unity。格雷厄姆编写了最早的 FPS 教程，许多人正是通过这些教程学习了在 Unity 中制作游戏的基础知识。

他意识到制作游戏不仅关乎技术，也关乎人性因素，于是转到苏塞克斯大学，担任人机交互方向的高级讲师。

2012 年 1 月，格雷厄姆离开学术界，创立了 Player Research，这是一家位于英国布莱顿的用户研究和游戏测试工作室。Player Research 与视频游戏工作室在游戏开发的各个阶段合作，从概念到发布，提供证据来支持设计决策，以提供最佳玩家体验。他们的客户包括 Sony、NaturalMotion Games、Mind Candy、Jagex、Ninja Theory、Madfinger Games、Hutch Games 和 Channel4 等众多公司。
