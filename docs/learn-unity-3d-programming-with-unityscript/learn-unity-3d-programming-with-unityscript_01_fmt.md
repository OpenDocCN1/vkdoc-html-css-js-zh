# 珍妮·苏瓦克

珍妮·苏瓦克在旧金山湾区出生并长大，在加州理工学院学习电气工程，之后在美国军队服役。她在军中从事航空电子系统的工作，之后转而进入医学院学习，最终又以飞行外科医生的身份重返军队。她对编程的兴趣始于初中时期的苹果 II 电脑，并将这份兴趣贯穿于整个军旅生涯，应用于各种项目中，从早期将维护零件追踪从纸质记录转为计算机，到编写人员追踪数据库系统和专有的电子病历程序（这些程序在当时远早于同类商业产品问世）。

退役后，珍妮将她钟爱的编程爱好转变为全职的自由职业，最初开发 iOS 应用，随后深入 Android 开发。她近期的成果之一是，在三星“关爱儿童希望”教育游戏开发大赛的五个类别中，她的作品赢得了其中两个类别的优胜，这些游戏将于今年晚些时候发布。她对 3D 游戏和增强现实技术特别感兴趣。
