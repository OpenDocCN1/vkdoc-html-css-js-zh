## 数据类型

为什么我们在代码清单 2-5 中，必须为 `document.write()` 内部的内容加上引号？这是因为 `document.write()` 只接受字符串类型的值。字符串用于存储文本字符序列，是 JavaScript 中五种基本（或称原始）数据类型之一。其中三种数据类型——数字（number）、字符串（string）和布尔值（Boolean）——用于存储数据，而另外两种则用于指定变量的当前状态。表 2-4 展示了这五种数据类型。

**表 2-4.** 基本数据类型

| 类型 | 赋值方式 | 使用示例 |
| --- | --- | --- |
| `Number` | 十进制 | `var num = 10;` |
| | 八进制（在数值前加 0） | `var num = 011;` |
| | 十六进制（在数值前加 0x） | `var num = 0x9A;` |
| | 浮点数，十进制（使用句点[.]） | `var fnum = 3.1415;` |
| | 浮点数，指数形式（使用句点[.]和 E） | `var fnum = -3.1E12;` |
| `Boolean` | `true` 或 `false` | `var flag = true;` |
| `String` | 由双引号或单引号包围的字符串 | `var str = "character string";` |
| | | `var str = 'character string';` |
| `null` | 对象已知存在，但没有值 | `var obj = null;` |
| `undefined` | 对象不存在、不返回值或尚未初始化 | |

除了基本数据类型，JavaScript 中还有复杂数据类型：

*   **对象（Object）：** 对象是多个基本数据类型和/或其他对象的集合，通常是预定义的或由开发者定义的。如果你要创建一个保龄球游戏，你很可能会有多个表示保龄球瓶的对象，以及另一个表示保龄球的对象。
*   **数组（Array）：** 数组是一组有索引且有序的数据。在保龄球游戏的例子中，你的保龄球瓶对象都可以存储在一个单独的数组中。添加到数组中的每个项目都会被分配一个编号，从 0 开始，每添加一个项目就增加 1。
*   **关联数组（Associative array）：** 关联数组是一组名称化数据的集合，这些数据不按特定顺序组合。与普通数组不同，关联数组可以将一个项目与任何其他值或项目配对。设想一下，假设我们的保龄球游戏是一个 3D 游戏，保龄球瓶上方悬挂着几盏灯。可以使用关联数组将每个保龄球瓶与特定的灯链接起来。
*   **函数（Function）：** 函数执行定义好的计算或一段代码。在保龄球游戏的例子中，如果保龄球与球瓶接触，可以使用一个函数来使保龄球瓶倒下。

我们稍后将更详细地介绍这些复杂数据类型。

**注意**

在 C/C++ 和 Java 等编程语言中，变量具有静态数据类型（如 `integer` 或 `string`），不能将一种数据类型的值赋给不同数据类型的变量。换句话说，如果你有一个 `integer` 类型的变量，就不能将一个字符串赋给该变量。

在 JavaScript 中，情况并非如此。任何数据类型的值都可以赋给一个变量，并且一个完全不同数据类型的值随后也可以重新赋给同一个变量。一个名为 `foo` 的变量可以先通过 `foo = 10;` 赋值为一个数字，然后紧接着下一行可以写 `foo = "bar";` 来给同一个变量赋一个字符串值。这种灵活性是 JavaScript 的一大优点，但缺点是，有时在执行计算时需要格外小心。我们稍后会看到这方面的例子。

## 了解变量的作用域

请暂时想象一下：你即将编写的程序发生在一个中世纪王国里，这个王国里有几个村庄和一座城堡。为了便于说明，假设这个王国的国王名叫鲍勃。在整个王国中，如果有人提到鲍勃，每个人都知道他们指的是国王。然而，如果在某个村庄里也有一个叫鲍勃的人呢？在那个村庄里，人们可能会称当地居民鲍勃为“我们的鲍勃”，但在城堡里，如果有人提到“鲍勃”，很可能大家都会默认指的是国王。

这实质上就是作用域的概念。它指的是变量在程序中的可见性。换句话说，作用域就是变量的上下文环境。要了解其工作原理，请执行以下操作：

```

创建一个函数，该函数创建一个代表王国中某个村庄的随机鲍勃的变量，为其分配一个 10 到 50 之间的随机年龄，然后将该年龄加 1 来模拟村民鲍勃庆祝生日，最后在屏幕上显示这个村民鲍勃的年龄。请通过输入清单 2-33 中的代码来实现。

```

请注意，当你在函数内部引用鲍勃时，需要使用 `this.bob` 来指定你指的是函数内部的鲍勃。为了解释村民鲍勃的可见性，我们说他具有函数作用域，而不是像国王鲍勃那样的全局作用域。

在你当前代码的下方输入清单 2-34 中的代码来调用 `villager` 函数。

**清单 2-34.** 调用村民函数

```
villager();
```

点击运行查看结果。你将看到国王鲍勃的年龄为 39，然后是村民鲍勃的一个随机年龄。

**注意：** 你不能在函数外部引用在函数内部创建的变量。这是函数作用域的限制。例如，我们不能在函数外部输入 `this.bob` 来引用村民鲍勃。在 `villager()` 函数之外，我们能看到或交互的鲍勃只有国王鲍勃。

## 用原型制作对象蓝图

原型本质上是一组可用于创建对象的蓝图。通过创建带有属性和方法的原型，我们可以轻松创建具有原型中指定属性和方法的新对象。要创建并使用一个包含名称和编程语言的软件原型，请执行以下操作：

清空你的代码。首先将原型创建为一个函数，然后通过输入清单 2-35 中的代码添加属性。

**清单 2-35.** 创建原型和属性

```
function Software() {
}

Software.prototype.name = "";
Software.prototype.language = "";
```

通过输入清单 2-36 中的代码，为原型创建一个显示其信息的函数。

**清单 2-36.** 创建原型函数

```
Software.prototype.output = function() {
    document.write(this.name + " is written in " + this.language + "<BR />");
};
```

输入清单 2-37 中的代码，创建一个新的对象 `accounting`，作为 `Software` 原型的实例；指定其属性的值；然后调用其函数以在屏幕上显示信息。

**清单 2-37.** 创建会计对象

```
var accounting = new Software();
accounting.name = "Spreadsheet Master";
accounting.language = "Java";
accounting.output();
```

点击运行。你会看到一条消息，说 Spreadsheet Master 是用 Java 编写的。尝试在 `accounting` 对象下方创建另一个对象，并调用 `output()` 函数。如果遇到问题，请查看 [`http://code.9leap.net/codes/show/19835`](http://code.9leap.net/codes/show/19835) 获取可运行的示例。

**注意：** 以上面的代码为例，以 `accounting` 作为对象名称，你可以随时通过输入类似 `accounting.secondLanguage = "C++";` 的内容来为该对象添加属性。这里，`secondLanguage` 之前并未用 `var` 或其他方式声明过。这是一种即时声明。函数也可以类似的方式添加到对象中，例如 `accounting.showLanguage = function() {document.write(this.language)};`。
